## 시트 → CSV 동기화

시트에서 수치를 바꿨으면 이 폴더에 반영하고 커밋한다. 방법 셋 중 하나:

1. **Aside에게**: "밸런스 시트를 저장소에 동기화해줘" (시트 읽기 → CSV 갱신 → 커밋까지)
2. **수동**: 시트에서 파일 > 다운로드 > CSV (탭별) → 위 대응표대로 저장
3. `sh sync_from_sheet.sh` — 시트가 링크 공개일 때만 동작 (현재 비공개라 1·2 사용)

**규칙**: CSV를 직접 고쳤으면 시트에도 반영할 것 (안 하면 다음 시트 동기화 때 롤백된다).

## 수치 수정 후 검증 (4대 체크리스트)

하네스 로드: Node 또는 브라우저 콘솔에서 `eval(balance_sim.js 내용)` → `eval(balance_sim_v2.js 내용)`

1. 앵커 정합 — 02_stages의 Min_Expected_Mult == `Target/(Turn_Limit x (15-K) x 2)` 재계산
2. 천장 여유 — 층별 최적 빌드 시뮬 EV ≥ Target x 1.2
3. 등장 비율 — Weight_Early에서 기초/(기초+배율) = 65~72%
4. 메타 균형 — 7~10층 3메타(몰빵/순환/역이용) 승률 편차 ≤ x1.5 · 배치 격차 max/min ≥ 1.5
   (2,000회 x 3시드, 같은 시드로 전후 비교)

## 확정 결정 로그 (2026-08-21)

- 합성 시스템(3개=Lv+1, x2 / 코어 +0.5x / 최대 Lv3) **채택**
- 유리공 연쇄 눈 제거 **층당 2회 제한** (리프트 x2.35 → x1.68)
- 제설차 레벨당 제거 **현행 유지** (β=0.52가 순환 고점을 자연 견제)
- 하강 2막 **보류** — 완주 코어 플레이 검증 후 재논의 (스키마 슬롯 예약됨)
- 진행 구조: **7734층 완주제** — 2_Stages는 정차 1~10 앵커일 뿐. 규칙은 10_progression.csv
