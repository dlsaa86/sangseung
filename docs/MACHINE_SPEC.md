## 1. 서사적 기능

**플레이어에게 보이는 것 (✅ 중립 어휘)**: 낡은 산업용 정제 장치. 불량체를 걸러 전력을 생산한다.

**진실 (🔴 노출 금지)**: 악신이 설계한 세계 수확 장치의 정제부.
"저항체"는 기억·의지·자아를 유지한 생존 의식이고, "정화"는 소거다.

→ 명칭·대사·에셋 이름에 **영혼·수확·자아를 쓰지 않는다.**
전력·불량체·오염·정화·출력·계약을 쓴다. → [PROJECT_VISION.md](PROJECT_VISION.md) §10.

## 2. 게임플레이 기능

층마다 최대 5회 스핀을 돌려 **요구 전력을 채우는 유일한 수단**이다.
계약·승객·부품이 이 장치의 판정 규칙을 바꾸고, 그 결과가 전력·위험·상승으로 이어진다.

## 3. 장치 구조 (확정)

### 3.1 전체

| 항목 | 값 |
|---|---|
| 형태 | 좁고 높은 산업용 본체. 뒷벽의 핵심 장치 |
| 통관 | **투명 수직 통관 3개**, 나란히 배치 |
| 결과창 | 통관마다 **3개** → **3열 × 3행 = 9칸** |
| 입력 장치 | **2단 기계식 통합 레버 1개** + **전력 확정 브레이크 1개** |
| 부속 | 하단 회수부 · 상단 재순환부 / 전력 탱크 / 계약·오염 계기판 / 과부하 경고등 / 자동 회전축 · 결과 잠금 장치 / 케이블·배전 장치 |
| 확장 | 향후 통관·수확창을 추가할 수 있는 **모듈 프레임**을 형상으로 확보 (구현은 범위 밖) |

**비율 요구 (확정)**
- 1인칭 시점에서 **한눈에 읽힐 정도의 크기**여야 한다
- **공간 대부분을 차지하면 안 된다**
- 플레이어·승객·아이템을 위한 빈 공간이 필요하다

**결과 표시 방식은 2안 미결** — ① 파이프 내부에 세로로 쌓인 심볼 3개씩
② 바로 옆 판독창에 3×3으로 명확히 표시.

## 4. 2단 기계식 통합 레버 (확정 — 2026-08-02)

> 일반 실행과 과수확은 **하나의 크고 무거운 2단 기계식 레버**로 통합한다.
> **기존 문서의 별도 과수확 레버 문구는 이 결정으로 폐기한다.**

### 4.1 구조

```
        ┌─────────────────┐
        │   손잡이 (Knob)  │  ← 성인이 한 손으로 조작 가능한 크기
        └────────┬────────┘
                 │
        ═════════╪═════════   ← 중심축 (회전 피벗)
                 │
     ①  ─────────┼─────────   첫 번째 걸림점  = 일반 스핀
                 │
     ②  ─────────┼─────────   두 번째 걸림점  = 과수확 (요구 전력 100% 달성 시 잠금 해제)
                 │              붉은 구간 · 보호 덮개
        ┌────────┴────────┐
        │  베이스 / 잠금쇠  │
        └─────────────────┘
```

- **회전축**: 중심축을 기준으로 회전하며 **아래로 당기는** 구조
- **조작 범위**: 첫 걸림점 → 두 번째 걸림점
- 레버·경고등·3×3 장치가 **하나의 조작 시스템처럼** 보여야 한다
- **경고등은 레버 가까이** 위치한다

### 4.2 상태 기계

| 조건 | 첫 걸림점 | 두 번째 걸림점 | 상태 문구 |
|---|---|---|---|
| 계약 미선택 | **비활성** (레버 사용 불가) | 잠김 | — |
| 요구 전력 미달 | **일반 스핀 실행** | 잠김 · 덮개 닫힘 | `수확 실행` |
| 요구 전력 100% 달성 | **스핀 실행되지 않음** | **잠금 해제 · 붉은 구간 노출** | `과수확 강행` |
| 남은 스핀 0 | — | 비활성 | — |

**활성 조건 (확정)**: `FloorPower >= RequiredPower` **그리고** 남은 스핀 ≥ 1.

### 4.3 입력 방식

| 동작 | 입력 |
|---|---|
| 일반 스핀 | **클릭 1회** |
| 과수확 | 두 번째 걸림점을 넘는 **`0.7~1.0초` 유지 입력** + 강한 금속 걸쇠 피드백 |
| 안전 종료 | 레버와 **분리된** 전력 확정 브레이크 또는 확정 버튼 |

> ⚠ 기술 부록 08 §15.2의 **「길게 누르기 금지」**와 충돌한다.
> MASTER PRD가 최상위이고 08 자신이 "충돌 시 MASTER PRD를 따른다"고 선언하므로 MASTER PRD가 이긴다.
> **해소**: 일반 상호작용은 클릭 1회, **유지 입력은 과수확 2단 구간 단 하나의 예외.**
> 근거는 실수 방지다 — *"과수확 입력은 실수로 발생하지 않도록"*.

> **과수확 선택을 메뉴 클릭만으로 처리하지 않는다.** 물리적 몸짓이어야 한다.

### 4.4 잠금 해제 연출

1. 기본 상태에서는 **잠겨 있거나 보호 덮개가 닫혀 있다**
2. 요구 전력 100% 달성 시 **내부 잠금쇠가 풀리고 짧은 경고 연출**
3. 붉은 두 번째 이동 구간이 노출된다
4. 레버 주변에 **현재 전력 · 유지 배수 · 추가 스핀 손실 조건**을 큰 단위로 표시

### 4.5 과수확 상호작용 연출 5단계 (확정)

1. 플레이어가 레버에 접근한다
2. **주변 기계음과 사이렌이 잠깐 줄어든다**
3. **승객이 플레이어와 레버를 바라본다**
4. 손을 올리는 순간 **0.3~0.7초의 정적**을 만든다
5. 레버를 끝까지 당기면 **경고등·진동·통관 회전이 동시에 재개**된다

이 5단계가 게임의 대표 장면이다. MASTER PRD §7.1:
> 안전하게 끝낼 수 있음에도 더 큰 보상을 위해 **위험을 자발적으로 선택하는 순간**을
> 게임의 대표 장면으로 만든다.

## 5. 경고등과 계기판

| 장치 | 표시하는 것 | 배치 |
|---|---|---|
| **전력 탱크** | 현재 전력 / 요구 전력 / 초과 전력 임계점 | 장치 옆, 통관과 시각적으로 연결 |
| **오염 계기판** | 정화되지 않은 저항과 다음 스핀 위험 | 장치 하단 또는 측면 |
| **계약 계기판** | 선택된 계약, 계약 저항의 패턴 성립 시 충전 | 계약 패널 근처 |
| **과부하 경고등** | 위험 단계, 과수확 해금 | **레버 가까이** |
| **결과 잠금 표시** | 통관별 결과 확정 상태 | 통관 상단 |

**계기판은 평면 UI가 아니라 물리적 조작부를 가진다** — 손잡이·스위치·봉인·계기 바늘.

**층수 표시는 출입구 위쪽**에 위치한다 (장치가 아니라 문 쪽).

## 6. 작동 순서와 상태 변화

```
[대기]
   │ 계약 선택 (미선택 시 레버 비활성)
   ▼
[레버 준비]
   │ 첫 걸림점까지 당김 (클릭 1회)
   ▼
[입력 잠금] ── 중복 입력 차단
   │
   ▼
[통관 3개 자동 회전]
   │ 결과가 한 칸씩 순차 공개  ← 9칸 동시 표시 금지
   ▼
[판정 — 판독 순서대로 점등]
   │ ① 정상/저항 구분 → ② 총개수 → ③ 기본 정화
   │ → ④ 직선·연결 → ⑤ 제거 대상 → ⑥ 신규 심볼
   │ → ⑦ 승객·부품 발동 → ⑧ 전력 임계점·위험
   ▼
[캐스케이드]  제거 → 빈칸 → 유입 → 재판정   (하드 캡 20, 생략 금지)
   │
   ▼
[잔류 효과 적용]
   │
   ▼
[입력 해제]
   │
   ├── 요구 전력 미달 ──> [대기] (남은 스핀 있으면)
   │
   └── 100% 달성 ──> [잠금 해제 연출] ──> 브레이크(안전 확정) 또는 2단 구간(과수확)
```

## 7. 애니메이션

| 대상 | 요구 |
|---|---|
| 레버 당김 | 물리적 무게감. 첫 걸림점의 저항, 두 번째 걸림점의 금속 걸쇠 |
| 통관 회전 | 세 통관 **동시** 회전, 결과는 **순차** 공개 |
| 결과 공개 | 총 **1.5~2.5초** (초기값, 조절 가능하게). 9칸을 동시에 즉시 표시하지 않는다 |
| 제거 전 정지 | **0.3~0.6초** (초기값) |
| 잠금 해제 | 짧은 경고 연출 |
| 과수확 정적 | **0.3~0.7초** |
| Collapse | 암전 0.3~0.7초 → 파열음 → 급강하 |

**캐스케이드 최종 속도는 승인 대기** — 잠그지 않는다.

## 8. 사운드

| 이벤트 | 소리 |
|---|---|
| 레버 당김 | 무거운 기계식 걸쇠 |
| 통관 회전 | 지속 모터음 |
| 결과 공개 | 칸마다 짧은 확정음 |
| 기본 정화 | 작고 빠른 보상음 |
| 직선 | 관통하는 강한 효과음 |
| 연결 붕괴 | 압착·파열 |
| 캐스케이드 | 단계마다 **사운드 층 누적** |
| 임계점 돌파 | 계기판 관통 강조음 |
| 과수확 해금 | 짧은 경고 사이렌 (지속 아님) |
| 위험 지속 | 저주파, 금속 응력음 |

**사이렌은 지속 재생하지 않는다.** 단계 상승·과수확 해금·레버 결정·사고 순간에만.

**심볼은 실루엣·색상·발광·사운드 중 최소 2개 이상으로 구분한다.**

## 9. 시각적 피드백

| 상태 | 표현 |
|---|---|
| 판정된 칸 | 명확한 **선·윤곽·점등** |
| 기본 정화 | 같은 종류에 **공통 외곽 윤곽선** 연결 |
| 직선 | 관통하는 한 줄 + **장치 내부 기계 부품이 방향에 따라 반응** |
| 4개 연결 | 연결 칸을 **하나의 면처럼** 채움 → 외곽선이 먼저 닫힘 → 내부 붕괴 |
| 빈칸 | **빈 공간을 명확히 보여준 뒤** 새 심볼 충전 |
| 캐스케이드 | 단계별 통관 조명·전력 탱크·사운드 **누적** |
| 계약 저항 | 외곽 링 또는 계기판 표식 (**과도한 희귀 연출 금지**) |
| 임계점 | 계기판을 **연속으로 관통하는 과정**을 시각·음향으로 강조 |

**자동 판정 순서를 천천히 보여주되 입력 타이밍을 요구하지 않는다.**

## 10. 고장·비정상 상태

| 상태 | 표현 |
|---|---|
| 캐스케이드 하드 캡 도달 | **오류가 아니라 안전 종료.** 명확한 로그를 남기고 정상 종료 |
| 가중치 합이 0 | **스핀 중단 + 명시적 오류 출력** |
| 과적 | 과부하 경고등, 요구 전력 증가 표시 |
| 장치 손상 (90~99% 구간) | 비상 상승 + 손상 연출 |
| Collapse | 사이렌·모터 끊김 → 암전·정적 → 금속 파열음 → 급강하 |
| 필수 참조 누락 | 개발 빌드에서 **즉시 명확한 오류** (조용히 실패 금지) |
