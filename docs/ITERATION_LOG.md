# ITERATION_LOG — 반복 라운드 기록

> **목적**: 각 개선 반복의 **변경 이유 · 기대 효과 · 실제 결과**를 기록한다.
> 측정 가능한 차이 없이 무작정 반복하지 않기 위한 장치다.
> **상위**: [QUALITY_GATES.md](QUALITY_GATES.md) §8 반복 개선 프로토콜

---

## 기록 규칙

1. **한 반복은 1~3개 문제만** 다룬다. 셋을 넘으면 무엇이 점수를 올렸는지 분리되지 않는다.
2. 캡처 조건(해상도·FOV·카메라 위치·품질 프리셋)을 **동일하게** 유지한다.
3. **검수 결과는 구현자가 쓰지 않는다.** `docs/runtime/VISUAL_VERDICT.md`의 독립 판정을 옮긴다.
4. **이전 버전보다 개선되지 않은 수정은 채택하지 않는다.** 채택하지 않은 것도 기록한다.
5. 같은 층위에서 **3번 실패한 항목은 4번째를 시도하지 않는다.** 구조 변경으로 전환한다.
