# 1. 확정 사항

**Notion 근거**: 07번 「확정 사항」

- 초기 결과판은 **3통관 × 3칸, 총 9칸**이다.
- 초기 프로토타입 심볼은 **정상 영혼 1종, 흡수체 1종, 증식체 1종**이다.
- 같은 저항체 **3개 이상**이 **서로 인접**하면 정화된다 (`D-20260801-03`).
- 직선·연결 패턴은 추가 보너스와 캐스케이드 조건이다.
- 결과는 **빠르게 움직이는 중이 아니라 정지된 3×3 판**에서 읽는다.
- **색만으로 구분하지 않고 실루엣·코어·표면 문양·움직임을 함께 사용한다.**

**현재 씬 대응**: `Sym_NormalSoul`, `Sym_Absorber`, `Sym_Proliferator` 3종 오브젝트가 존재한다.

> ℹ️ **명명 불일치 (경미)**: 증식체의 식별자가 Notion 08 §6.2는 `replicator`, 현재 씬 오브젝트는
> `Sym_Proliferator`다. 기능은 동일하다. 데이터 자산 ID를 정리할 때 한쪽으로 통일하면 좋다.

# 2. 공통 형태 규칙

**Notion 근거**: 07번 「공통 형태 규칙」

- 모든 심볼은 **통관 안에서 안정적으로 순환할 수 있는 유사한 구형 부피**를 가진다.
- **외곽 실루엣과 내부 코어는 종류마다 명확히 다르게** 만든다.
- **작은 글자와 복잡한 표면 장식은 사용하지 않는다.**
- 정면뿐 아니라 **회전 중에도 인식되도록** 문양을 여러 면에 반복하거나 **내부 코어 자체를 차별화**한다.
- 프로젝트 팔레트와 조화를 유지한다: **산화 철, 낡은 황동, 오염된 유리, 탈색된 뼈색**.
- 정상 영혼은 "완전히 선하고 깨끗한 인상"보다 **이미 정제·순응된 존재**처럼 보이게 한다.
- 저항체는 "단순한 악성 바이러스"보다 **내부에서 무언가가 버티거나 움직이는 인상**을 준다.

**저항체 공통 규칙** (07번 「저항체 공통 규칙」):
- 정상 영혼보다 **불규칙한 외곽 또는 내부 구조**를 가진다.
- **종류별로 한 가지 큰 상징만** 사용한다.
- 정화 계약 적용 시 **외곽 링 또는 계기판 표식**으로 보상 증가를 표시한다.
- 3개 기본 정화 시 같은 종류 전체에 **공통 윤곽선이 연결**된다.
- 패턴 성립 시 개수 정화보다 **더 강한 선·면·균열 연출**을 사용한다.

> 🔒 **서사 제약 (05번 스포일러)**: 저항체는 후반으로 갈수록 "내부에서 심장·눈·뼈와 유사한
> 생명의 흔적"이 드러나야 한다. **초기 디자인이 이 여지를 막지 않아야 한다** — 즉 저항체 코어를
> 순수 기하 도형으로 완결시키지 말고, 후속 단계에서 유기적 요소를 넣을 내부 공간을 남긴다.
> 단, 초·중반 UI와 공개 문구에는 **영혼·수확·자아 표현을 쓰지 않는다.**

# 3. 심볼 3종 상세

## 3.1 정상 영혼 (`normal_soul`)

**기능** (07번 / 08 §6.2):
- 한 개마다 기본 전력을 제공한다. 위치·패턴과 무관하게 **즉시 수확**된다.
- **정화 대상이 아니다. 잔류 효과가 없다.**
- 기본 전력: **Notion 참고값 10** (임시값)

**시각 언어** (07번 「정상 영혼 — 시각 언어」):
- **둥글고 안정된 외곽**
- **일정한 방향의 느린 회전**
- **부드럽고 반복적인 내부 맥동**
- **표면 문양이 정돈되어 있으며 돌출이 적음**
- 결과 판정 시 **전력 탱크 방향으로 흡수되는 명확한 이동**

**후속 변형 후보** (프로토타입 제외): 고밀도 영혼(더 큰 기본 전력) / 공명 영혼(인접 정상 영혼 가치 증가) / 기억 영혼(특정 승객 발동) / 불안정 영혼(높은 전력과 저항 생성 위험)

## 3.2 흡수체 (`absorber`)

**기능** (07번 / 08 §6.2):
- 정화되지 않으면 **저장 전력을 감소시킨다.**
- 정화 기본 보상: **Notion 참고값 18** / 잔류 대가: **남은 1개당 현재 층 전력 −5**

**시각 언어** (07번 「흡수체 — 시각 언어」):
- **중앙이 비어 있거나 안쪽으로 빨려 들어가는 코어**
- **표면에서 중심으로 향하는 홈**
- **전력 탱크 방향으로 가는 가느다란 흡수 실선**
- **낮고 지속적인 진동**

## 3.3 증식체 (`replicator` / 씬 `Sym_Proliferator`)

**기능** (07번 / 08 §6.2):
- 정화되지 않으면 **다음 스핀의 증식체 출현 가중치를 높인다.**
- 정화 기본 보상: **Notion 참고값 15** / 잔류 대가: **남은 1개당 다음 스핀 가중치 +5%**, 층 종료 시 초기화

**시각 언어** (07번 「증식체 — 시각 언어」):
- **하나의 구체 안에 작은 핵이 여러 개** 존재
- **표면에 분열선과 새싹처럼 돋는 돌기**
- **판정 종료 직전 작은 핵이 복제될 듯 팽창**
- **고음의 반복 클릭 또는 맥동**

# 4. 판독축 대조표 — `VISUAL_SPEC.md` §4 대응

`VISUAL_SPEC.md` §4는 "정상 영혼, 흡수체, 증식체는 **색상 하나에만 의존하지 않고** 다음 중
**최소 세 가지가 달라야 한다**"고 요구하며 6개 축을 지정한다. 아래는 Notion 07번의 서술을
그 6축에 대응시킨 것이다.

| 판독축 | 정상 영혼 | 흡수체 | 증식체 | 3자 구분 | 회색조 유효 |
|---|---|---|---|---|---|
| **① 외곽 실루엣** | 둥글고 **안정된** 외곽. 돌출 적음 → **매끈한 구** | 표면에서 중심으로 향하는 **홈** → **오목하게 파인 구** | 표면에 **새싹처럼 돋는 돌기** → **볼록하게 돋은 구** | ✅ **매끈 / 오목 / 볼록** | ✅ 유효 |
| **② 내부 오브제·패턴 (코어)** | 부드럽고 반복적으로 맥동하는 **단일 코어** | **중앙이 비어 있음** — 코어 공백 | **작은 핵이 여러 개** | ✅ **1개 / 0개(공백) / 다수** | ✅ 유효 |
| **③ 발광 방식** | 판정 시 전력 탱크 방향 **흡수 이동** | **전력 탱크 방향으로 가는 가느다란 흡수 실선** (상시) | 판정 종료 직전 **핵이 팽창** | ⚠️ **부분** — §4.1 참조 | ⚠️ 부분 |
| **④ 움직임·맥동** | **일정한 방향의 느린 회전** + 규칙적 내부 맥동 | **낮고 지속적인 진동** (회전 언급 없음) | **간헐적 팽창** (판정 종료 직전) | ✅ **느린 회전 / 미세 진동 / 간헐 팽창** | ✅ 유효 |
| **⑤ 텍스처 밀도** | 문양이 **정돈**되어 있음 → **낮음·균일** | 중심을 향한 **방사형 홈** → **중간·방향성 있음** | **분열선 + 돌기** → **높음·불규칙** | ✅ **균일 / 방사형 / 불규칙** | ✅ 유효 |
| **⑥ 공개 사운드** | ⚠️ Notion 07번에 **명시 없음** | **낮고 지속적인 진동** → 저주파 | **고음의 반복 클릭 또는 맥동** | ⚠️ **부분** — §4.2 참조 | — (청각축) |

## 4.1 ③ 발광 축 — 부분 자료 부족

- Notion 07번은 세 심볼의 **발광 방식을 직접 규정하지 않는다.** 위 표의 내용은 각 심볼의
  "판정 시 이동·실선·팽창" 서술에서 발광으로 읽을 수 있는 부분만 옮긴 것이다.
- 관련 근거는 있다:
  - 08 §6.1 `SymbolDefinition` 필수 속성에 **"색상·발광 식별값"**이 포함된다.
  - Notion MASTER PRD §12.4 — "정상 영혼과 저항체는 **발광·맥동·내부 코어를 데이터로 조정**한다."
- **판정**: 발광은 **데이터로 조정 가능해야 한다는 요구만 확정**돼 있고, 심볼별 구체 발광 사양은
  **자료 부족**이다. 승인 대기 항목(`VISUAL_SPEC.md` §11 "최종 색 조합")에 해당하므로
  **하나의 최종안으로 잠그지 않고 2~3개 프리셋으로 구현**한다.

## 4.2 ⑥ 사운드 축 — 정상 영혼만 자료 부족

- 흡수체(저주파 지속 진동)·증식체(고음 반복 클릭)는 Notion 07번에 명시돼 있다.
- **정상 영혼의 결과 공개 사운드는 07번에 없다.**
- 관련 근거: 08 §6.1에 "결과 공개 사운드"가 `SymbolDefinition` 속성으로 있고,
  08 §16.4 사운드 목록에 "각 칸 결과 공개", "**정상 영혼 수확**", "저항체 정화"가 별개 항목으로 있다.
- **판정**: 정상 영혼 사운드는 **존재해야 하지만 성격이 미지정** — 자료 부족.

## 4.3 회색조 판정 결론

- **색을 완전히 제거해도 ①②④⑤ 네 축이 작동한다.**
  - ① 매끈 / 오목 / 볼록
  - ② 코어 1개 / 공백 / 다수
  - ④ 느린 회전 / 미세 진동 / 간헐 팽창
  - ⑤ 균일 / 방사형 / 불규칙
- `VISUAL_SPEC.md` §4의 **"최소 세 가지" 요건을 네 축으로 초과 충족**한다.
- Notion 07번 검수 체크리스트의 **"흑백 또는 색각 차이가 있어도 실루엣과 코어로 구분되는가?"**
  항목도 ①②로 충족된다.
- ⚠️ **단, 이는 Notion 사양대로 구현했을 때의 판정이다.** 현재 씬 심볼의 실제 형상이 이 사양을
  따르는지는 **미검증**이다 — `MASTER_PRD.md` §11 "룰렛 정면" 캡처를 회색조로 변환해 확인해야 한다.

## 4.4 ⚠️ 레퍼런스 이미지는 이 기준을 만족하지 못한다

- `docs/references/elevator/d5cfa65b-ad3a-401a-a445-708b9d7cb0bf.png`의 3×3 결과판은
  **9칸이 전부 동일하게 생긴 붉은 구체**다.
- 실루엣·코어·텍스처 차이가 없어 **①②⑤ 축이 전부 무효**이며, 색조차 단일하다.
- **판정: 심볼 디자인 레퍼런스로 사용 금지.** 이 이미지는 분위기·재질·조명 참고로만 쓴다.
  (상세 판정은 `VISUAL_BIBLE.md` §5)

# 5. 정화 연출 — 3종 × 3패턴

**Notion 근거**: 07번 「흡수체 — 정화 연출」, 「증식체 — 정화 연출」

| 패턴 | 흡수체 | 증식체 | 정상 영혼 |
|---|---|---|---|
| **기본 정화 (같은 종류 3개↑)** | **중심 공백이 닫히며 붕괴** | **내부 핵이 동시에 터짐** | 정화 대상 아님 |
| **직선 3개** | **세 심볼을 관통하는 절단선** | **분열선이 직선으로 이어져 연쇄 폭발** | 정화 대상 아님 |
| **4개 이상 직교 연결** | **연결된 코어가 한꺼번에 압착되고 빈칸으로 빨려 나감** | **작은 핵이 주변 칸으로 퍼지려다 역으로 빨려 들어감** | 정화 대상 아님 |
| **수확 (해당 없음)** | — | — | **전력 탱크 방향으로 흡수되는 명확한 이동** |

**설계 의도 관찰**: 두 저항체의 연출이 **정반대 방향의 운동**을 쓴다.
- 흡수체 = **안으로 빨아들이는 것이 무력화된다** (공백이 닫힘 / 압착 / 빨려 나감)
- 증식체 = **밖으로 퍼지려는 것이 차단된다** (핵 폭발 / 연쇄 폭발 / 퍼지려다 역으로 빨림)

이 대비는 색 없이도 두 저항체를 구분시키는 **다섯 번째 판독축**으로 작동한다.

# 6. 패턴 시각화 규칙

**Notion 근거**: 07번 「패턴 시각화」

## 6.1 개수 기본 정화
- 해당 종류 **3개 이상에 같은 외곽 윤곽선**을 표시한다.
- **위치가 떨어져 있어도 번호·색상·맥동을 통일**한다.
- 보상 표시는 **작고 빠르게** 처리한다.

## 6.2 직선 3개
- 가로·세로·대각선을 **관통하는 한 줄의 강한 효과**
- **직선 방향에 따라 장치 내부 기계 부품이 반응**한다.
- 기본 정화보다 **큰 충격과 배수 표시**

> ⚠️ **대각선 주의**: `DEVICE_DESIGN_SPEC.md` §3.1에서 확인한 대로 현재 씬의 3×3 격자는
> 열 간격 0.50m, 행 간격 0.40m로 **정사각이 아니다.** 대각선이 45°가 아니라 약 38.7°로 기울어지므로
> 관통선 VFX를 45° 고정으로 만들면 칸을 벗어난다. **격자 비례를 전제로 설계해야 한다.**

## 6.3 4개 이상 직교 연결
- 상하좌우로 연결된 칸을 **하나의 면처럼 채운다.**
- **연결 덩어리의 외곽선이 먼저 닫힌 뒤 내부가 붕괴**한다.
- 제거된 칸에 **빈 공간을 명확히 보여준 뒤** 새 심볼을 충전한다.

## 6.4 특수 패턴
- L·T·십자·고리 등은 **프로토타입에서 제외**한다 (`MASTER_PRD.md` §4.2와 일치).
- 추가 시 모양마다 고유한 장치 반응과 짧은 명칭을 부여한다.

# 7. 캐스케이드 시각 규칙

**Notion 근거**: 07번 「캐스케이드 시각 규칙」

- **제거 → 빈칸 → 새 심볼 유입 → 재판정 순서를 생략하지 않는다.**
  (저장소 `MASTER_PRD.md` §6과 동일 요구)
- **너무 빠른 연쇄에서도 각 단계의 원인이 최소 한 번은 읽혀야 한다.**
- 캐스케이드 단계가 높아질수록 **통관 조명, 전력 탱크, 사운드 층을 누적**한다.
- 숫자와 효과가 화면을 가리지 않도록 **큰 배수 하나와 핵심 발동 승객만 강조**한다.
  (저장소 `MASTER_PRD.md` §6.1 "한 화면에 모든 숫자를 동시에 띄우지 않는다"와 일치)

**연출 타이밍 참고값** (08 §16.1·§16.2):
- 9칸을 동시에 즉시 표시하지 않고 **열 또는 칸 단위로** 공개
- 총 결과 공개 시간 **1.5~2.5초 범위로 조절 가능**
- **제거 전 0.3~0.6초 정지**
- 정상 영혼과 저항체는 실루엣·색상·발광·사운드 중 **최소 2개 이상**으로 구분
  → ⚠️ 저장소 `VISUAL_SPEC.md` §4는 **"최소 3가지"**를 요구한다. **저장소가 더 엄격하므로 3가지를 따른다.**

# 8. 저항 계약 시각 표시

**Notion 근거**: 07번 「저항 계약 표시」

- 계약한 저항체에는 **장치 외곽의 전용 표식과 동일한 링**을 표시한다.
- 출현률 증가·정화 보상·잔류 대가를 **계약 선택 화면에서 함께** 보여준다.
- **계약 심볼이 등장할 때 과도한 희귀 연출을 사용하지 않는다.**
  → 근거: "많이 나와야 하는 대상이므로 일관된 강조만 사용한다."
- 계약한 저항의 패턴이 성립하면 **전용 계약 계기판이 충전**된다.

**현재 씬 대응**: `ContractPanel`, `ContractPlaque_0/1/2`, `InstrumentPanel`.
**미검증**: 심볼 자체에 붙는 "외곽 링"의 존재 여부 → **자료 부족.**

# 10. 후속 저항체 후보 — 프로토타입 제외

**Notion 근거**: 07번 「후속 저항체 후보」, 01번 「잔류 저항」

`MASTER_PRD.md` §4.2가 "추가 저항체"를 **명시적 제외**로 지정한다. **구현하지 않는다.**
심볼 데이터 구조를 설계할 때 확장 여지만 남기면 된다.

| 저항체 | 기능 | 시각 언어 (07번) |
|---|---|---|
| **고정체** | 다음 스핀의 한 칸 또는 한 통관을 잠근다 | 자물쇠·갈고리·**무거운 앵커 코어** |
| **위장체** | 정상 영혼처럼 계산된 뒤 판정 말미에 저항으로 드러난다 | 정상 영혼과 비슷하되 **내부 회전 방향과 그림자가 다르다** |

| **무게체** | 요구 전력 또는 다음 층 실질 적재량을 높인다 | **밀도 높은 금속·뼈 덩어리** |
