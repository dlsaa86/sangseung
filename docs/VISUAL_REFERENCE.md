# 0. 이 문서가 왜 중요한가

지금까지 그래픽 작업은 **숫자**(G-1~G-8)와 **평가자의 지적**으로만 방향을 잡았다.
그 둘은 「무엇이 잘못됐는가」는 말해 주지만 **「무엇이 되어야 하는가」는 말하지 않는다.**
16라운드 동안 스타일 점수가 2.20 에 붙어 있던 이유의 일부가 그것이다 —
**도달 목표의 그림이 없었다.**

이 레퍼런스는 그 그림이다. 그리고 **우연이 아니라 정확히** 우리가 숫자로 쫓던 것들을
전부 담고 있다 — 아래 §4 가 그 대응표다.

# 1. 공간 구조 (1인칭, 문 안쪽에서 본 뒤)

```
        ┌─────────── 천장: 리벳 패널 + 대들보 ───────────┐
        │              ● 철망 씌운 백열등 (유일한 주광)    │
 [02▲▼] │                                              │
 ┌──────┤   ┌──────────────────┐  [🔴]                 │ STORAGE
 │가위문 │   │  ○ ○ ○           │  ⚠과수확              │ ⚠SAFETY
 │(좌벽) │   │  ○ ○ ○  ← 3×3    │  ┃레버┃               │ FIRST
 │       │   │  ○ ○ ○           │  ┌────────┐          │ ┌───선반───┐
 │  ‖    │   │  ⊙ ⊙ ⊙  ← 해치   │  │POWER   │          │ │상자·공구함│
 └──────┤   └──────────────────┘  │014/100 │          │ └─────────┘
        │        (뒷벽 = 장치벽)     └────────┘          │
        └────── 바닥: 마름모 무늬 강판 + 매립 볼트 ────────┘
```

| 위치 | 무엇이 있나 |
|---|---|
| **좌벽** | **접이식 가위문**(마름모 격자). 그 너머로 **어두운 승강로**와 멀리 따뜻한 불빛 하나 |
| 좌벽 상단 | **층수 표시** — 어두운 금속판에 붉은 세그먼트 「02」 + 위/아래 **붉은 삼각 화살표** |
| **천장** | 리벳 패널 + 가로 대들보. **철망 씌운 백열등 하나**가 아래로 원뿔형 빛을 뿌린다 |
| **뒷벽 (정면)** | 룰렛 장치. 리벳 캐비닛에 **원형 현창(porthole) 3×3**, 각 창 안에 **붉은 발광 구체**. 그 아래 **원형 해치 3개** |
| 장치 우측 | 위: **붉은 버섯 버튼**. 가운데: **「OVERHARVEST / EXTREME DANGER」 황·흑 위험 라벨**. 아래: **붉은 손잡이 대형 레버**가 세로 슬롯 안. 맨 아래 **「EXECUTE ↓」** |
| 장치 우측 하단 | **전력 계기** — 검은 베젤에 붉은 숫자 「POWER / 014 / 100 / REQUIRED」 |
| **우벽** | **「STORAGE」 스텐실**, **「SAFETY FIRST — SECURE ALL CARGO BEFORE MOVEMENT」 표지**(픽토그램 포함), **선반**에 나무·금속 상자(「TOOLS 01 33」·「SUPPLIES 12」)가 **붉은 스트랩**으로 묶여 있고 공구함·깡통 |
| **바닥** | 마름모·육각 무늬 **강판**, 매립 볼트 커버 |

---

# 2. 조명 — 이것이 이 이미지의 핵심이다

- **주광이 하나다.** 철망 씌운 백열등. 따뜻한 호박색, 원뿔형 낙하, **빠른 감쇠**
- **나머지는 거의 검정.** 구석·바닥 가장자리·좌벽 하단이 완전히 죽어 있다
- **보조 발광은 붉은색뿐** — 현창의 구체, 층수 숫자, 계기 숫자, 버섯 버튼
- **가위문 너머 멀리 따뜻한 점광 하나** — 깊이를 만드는 유일한 배경 요소
- 강한 **비네트**. 프레임 가장자리가 급격히 어둡다

**이것이 `VISUAL_BIBLE` §2.1 의 「제한적인 국소 조명과 빠른 감쇠」의 그림이다.**
지금 우리 씬은 앰비언트가 전체를 고르게 들어 올려 그 반대에 가깝다.

---

# 3. 재질과 팔레트

| 축 | 레퍼런스 |
|---|---|
| 지배색 | **탁한 올리브-갈색 + 차콜.** 채도가 전반적으로 매우 낮다 |
| 강조색 | **붉은색 하나** — 숫자·구체·레버 손잡이·스트랩·버튼 |
| 따뜻함 | 백열등의 호박색 원뿔. **그 외에는 따뜻한 면이 거의 없다** |
| 표면 | **모든 면에 텍스처가 있다** — 녹, 때, 페인트 벗겨짐, 리벳, 패널 이음매, 얼룩 |
| 무지 면 | **없다.** 가장 평평한 벽조차 얼룩과 이음매를 갖는다 |
| 글자 | **스텐실**로 표면에 인쇄돼 있다 — 떠 있는 UI 가 아니다 |

# 4. 우리가 숫자로 쫓던 것과의 대응 — **레퍼런스가 전부 만족한다**

| 우리 축 | 현재 | 레퍼런스가 하는 것 |
|---|---|---|
| **G-2** p5 ≤ 24 | 실패 | 구석이 **완전히 검다** |
| **G-2** p95 ≥ 170 | 실패 (화각 안에 밝은 광원이 없다) | **백열등 자체가 프레임 안에 있다** |
| **G-3** 발광원 ≥ 5종 | 4/8 장 | 백열등 · 현창 구체 9 · 층수 숫자 · 계기 숫자 · 버섯 버튼 · 승강로 원경 = **6종** |
| **G-1** 텍스처 | 3.98 | 모든 면에 녹·때·리벳 |
| **G-5** 빈 평면 ≤ 18% | 22.7% | **선반·상자·표지·스텐실·해치**가 벽을 채운다 |
| `UP-VIS-02` 탁한 천장등 vs 차가운 통관 발광 | 미해결 | 천장등 따뜻함 ↔ **장치 발광 붉음**으로 분리 |
| `UP-VIS-08` 슬롯머신 아님 | 2/5 | **현창 3×3** 은 계기판이지 릴이 아니다 — 세로 릴 구조가 없다 |
| `B-2 #4` 3×3 판독 | 4/5 | 원형 창 아홉 개가 **격자로 명확** |
| 과수확 레버 구분 | 지적 반복 | **위험 라벨 + 세로 슬롯 + 붉은 손잡이**로 실행 레버와 완전히 다른 형상 |
| `UP-SPACE-06` 적재 동선 | 미검증 | **선반에 스트랩으로 고정** — 바닥을 막지 않는다 |
| 층수 표시 | `16` 에서 소실 | **문 위 전용 패널**, 세그먼트 숫자 + 방향 화살표 |

**독립적으로 도출한 8개 축을 레퍼런스가 전부 만족한다.**
이것은 우리 축이 옳았다는 방증이기도 하고, **지금 필요한 것이 축 조정이 아니라 제작**이라는 뜻이기도 하다.

# 5. 기존 명세와의 긴장 — 두 가지를 기록한다

## 5.1 텍스처 밀도가 「저해상도 손그림 픽셀」보다 높다

`VISUAL_BIBLE` §2.1 #5 는 「저해상도 손그림 픽셀 텍스처」를 요구하고 §2.2 는
「**not pixel art**」를 함께 적는다. 레퍼런스는 그 사이에서 **후자 쪽에 가깝다** —
사진 기반은 아니지만 손그림 픽셀보다 밀도가 높다.

**판정**: `VISUAL_BIBLE` §2.3 의 해소 기준(「텍스처 확대 시 픽셀 그레인이 보이고,
실루엣과 조명은 3D 로 읽힐 것」)을 그대로 쓴다. 레퍼런스는 그 기준을 만족한다.
**사용자가 제시한 것이 기준이므로 이쪽이 우선한다.**

## 5.2 「좁고 높은」과 4배 확대

레퍼런스는 **좁다.** 우리는 사용자 지시로 바닥을 4배로 넓혔다(7.20 → 28.80 m²).

**둘은 충돌하지 않는다** — 사용자가 확대를 지시한 이유가 「승객이 탑승해야 하니까」였고,
레퍼런스의 **우벽 선반 구역**이 그 확장분을 쓰는 방식을 보여 준다.
확대된 폭은 **빈 바닥이 아니라 적재·설비 구역**이 되어야 한다는 것이 레퍼런스의 답이다.

# 6. 제작 순서 (레퍼런스 기준)

우선순위는 **화면 면적 × 현재 결손**이다.

| 순위 | 항목 | 왜 |
|---|---|---|
| **1** | **조명 재구성** — 철망 백열등 1개 주광 + 급감쇠 + 앰비언트 대폭 하향 | G-2 두 축을 동시에 연다. 지금 진행 중인 작업과 같은 것 |
| **2** | **우벽 선반 + 스트랩 상자 + 스텐실 표지** | G-5 22.7% → 18% 이하. 확대된 폭의 용도를 정한다 |
| **3** | **장치를 현창 3×3 으로 재설계** | `UP-VIS-08` 슬롯머신 회피의 **구조적** 해답. 세로 릴이 사라진다 |
| **4** | **좌벽을 접이식 가위문으로** + 승강로 원경 조명 | 깊이·공간 정체성 |
| **5** | 층수 표시 패널 (세그먼트 + 방향 화살표) | `16` 층수 소실 해결 |
| **6** | 바닥 마름모 강판 + 매립 볼트 | 바닥 무지 면 |
| **7** | 과수확 레버 슬롯 + 위험 라벨 형상화 | `UP-FIX-03` |

**각 단계마다 한 축만 바꾸고 캡처 → 측정한다.** 이 원칙이 이번 세션에서
타일링 모델을 한 번의 캡처로 반증했다.
