# Graphics Target — 「Cloverpit 수준」을 측정 가능한 축으로

> 상태: 2026-08-02 사용자 지시로 신설. `DECISION_LOG.md` 「그래픽 완성도를 현재 범위로 승격한다」.
> 상위 문서: `VISUAL_SPEC.md` → `VISUAL_BIBLE.md` §2.1 스타일 락 → 이 문서.
> **이 문서는 방향을 바꾸지 않는다. 완성도의 통과선만 정의한다.**

---

# 0. 왜 이 문서가 필요한가

독립 시각 평가가 **14회 연속 REJECT** 이고 스타일 점수가 **2.20/5 에서 14라운드 동안
한 칸도 움직이지 않았다.** 판독성은 2.50 → 2.64 로 겨우 움직였다.

원인은 조정 실패가 아니다. 두 항목이 같은 것을 말한다.

- `UP-FIX-34` — `Ascend/Stylized` 를 쓰는 렌더러가 사실상 `CarShell_*` 뿐이다.
- `UP-VIS-01` — 텍스처 에셋 4장이 **어느 머티리얼에도 배선되지 않았다.** 화면 텍스처 0장.

**평가받고 있는 대상이 아직 그레이박스다.** 회색 프리미티브를 몇 번 더 조정해도
「상업적 완성도」는 2점에서 안 움직인다. 그것이 그레이박스의 정확한 점수이기 때문이다.

그래서 이 문서는 **무엇을 만들면 그 축이 움직이는가**를 숫자로 적는다.
5점 척도 인상 평가와 달리 이 숫자들은 캡처 PNG 에서 기계가 잰다
(`tools/capture-metrics.ps1` — `UP-VIS-12` 가 지적한 「절대 5점 척도 금지」 위반을 피하는 길이기도 하다).

---

# 1. 레퍼런스가 무엇이고 무엇이 아닌가

**Cloverpit** 은 PS1 로우폴리 지오메트리 + 강한 포스트 처리 + 고밀도 저해상도 텍스처 +
소수의 강한 실용 광원으로 이루어진 계열이다. `VISUAL_BIBLE.md` §2.1 의 스타일 락
(`stylized low-poly industrial occult horror / PS2-era survival-horror`)과 **같은 방향**이다.

| 레퍼런스에서 가져오는 것 | 가져오지 않는 것 |
|---|---|
| 모든 표면에 텍스처가 있다 (무지 면 0) | 폴리곤 수 증가 |
| 소수의 강한 광원 + 깊은 그림자 | 물리 기반 재질(PBR 금속·거칠기 워크플로) |
| 발광이 판독의 주 채널 | 사실적 GI·레이트레이싱 |
| 강한 포스트 (그레인·비네트·블룸·색보정) | 슬롯머신·카지노 어휘 (`VISUAL_SPEC` §1 명시 금지) |
| 빈 평면이 없는 공간 밀도 | 판독성을 해치는 수준의 색수차·흔들림 (`VISUAL_SPEC` §8) |
| 촉각적인 물리 반응 | 정밀 조준을 요구하는 상호작용 (`B-5 #14`) |

**Cloverpit 보다 높은 점수를 목표로 삼지 않는다** — `.claude/visual-criteria.md` §C 의 원칙이다.
격차가 가장 큰 축부터 순차적으로 줄인다. 지금 격차가 가장 큰 축은 **텍스처 커버리지**다(0%).

# 2. 측정 축과 통과선

전부 `Captures/TenFloor/` 고정 세트 24장(1920×1080)에서 기계가 잰다.
「대표 8장」은 `01·02·06·09·12·15·18·21`.

## G-1. 텍스처 커버리지 — 지금 0 인 축

| 지표 | 현재 | 통과선 |
|---|---|---|
| 텍스처가 배선된 머티리얼 비율 | **0 / 47** | **≥ 40 / 47** |
| 무지(`_BaseMap` = white) 렌더러 수 | 전부 | **0** (발광 전용 면 제외) |
| 대표 8장의 **국소 분산** 중앙값 | 미측정 | **≥ 12.0** (8×8 블록 표준편차의 중앙값) |

**국소 분산이 이 축의 핵심 지표다.** 「텍스처를 배선했다」는 머티리얼을 세는 것이고,
「화면에 텍스처가 보인다」는 화소를 세는 것이다. 이 저장소는 그 둘을 혼동해
두 번 실패했다. 무지 면은 8×8 블록 표준편차가 1 미만이고, 손그림 픽셀 텍스처가 있으면
10 을 넘는다. 조명 그라디언트만으로는 8을 못 넘는다.

## G-2. 조명 대비 — 어둠이 있어야 빛이 보인다

| 지표 | 통과선 | 왜 |
|---|---|---|
| 휘도 5퍼센타일 | **≤ 24** | 깊은 그림자가 실재해야 한다 |
| 휘도 95퍼센타일 | **≥ 170** | 강한 실용 광원 |
| 휘도 중앙값 | **36 ~ 96** | 전체가 회색으로 뜨지 않는다 |
| 대표 8장 전부에서 위 셋 충족 | **8/8** | 한 장만 어두운 것은 조명이 아니라 우연이다 |

⚠ **회귀 감시 유지**: 좌벽 ΔL(위험 4단계) **≥ 15** 는 그대로 산다. 대비를 올리다
위험 단계가 뭉개지면 그 자체로 REJECT 다 — 14차가 지정한 감시축이다.

## G-3. 발광 — 판독의 주 채널

| 지표 | 통과선 |
|---|---|
| 발광 화소 비율 (휘도 ≥ 200 인 화소) | **1.0% ~ 6.0%** |
| 발광이 있는 대표 장 | **8/8** |
| 발광원 종 수 (천장등·통관·계기·레버 레일·경고등) | **≥ 5** |

하한이 있는 이유: 어두운 공간에서 발광이 없으면 아무것도 안 읽힌다.
상한이 있는 이유: 6% 를 넘으면 블룸이 화면을 먹고 `VISUAL_SPEC` §8 의
「로우파이를 명분으로 판독성을 희생하지 않는다」에 걸린다.

## G-4. 계단 셰이딩이 실제로 보이는가 — `UP-FIX-35`

| 지표 | 현재 | 통과선 |
|---|---|---|
| 벽면 200px 주사선의 평탄 구간 수 | **156개 (최장 7px)** | **≤ 24개, 최장 ≥ 20px** |
| 24장 중 계단이 관측되는 장 | **0장** | **≥ 12장** |

「셰이더가 돈다」와 「계단이 보인다」는 다른 것이고, 14차 실측이 24장 중 0장이었다.
평탄 구간이 156개라는 것은 사실상 연속 그라디언트라는 뜻이다.

## G-5. 공간 밀도 — 빈 평면이 없다

| 지표 | 통과선 |
|---|---|
| 대표 8장의 **빈 평면 비율** (32×32 블록 중 표준편차 < 4 인 블록) | **≤ 18%** |
| 캐빈 내부 고유 프롭 종 수 | **≥ 24** |
| 4배로 넓어진 바닥에서 빈 그레이 바닥이 차지하는 화소 | **≤ 12%** |

바닥을 4배로 넓히면 **빈 평면 비율이 자동으로 나빠진다.** 이 지표는 확대가
「공간이 커졌다」가 아니라 「채우지 않은 바닥이 커졌다」로 끝나는 것을 막는다.

## G-6. 포스트 체인

| 항목 | 요구 | 상한 |
|---|---|---|
| Tonemapping | 활성 | — |
| Bloom | 활성 (발광에만 걸리는 임계) | 화면 평균 휘도 상승 ≤ 12% |
| Vignette | 활성 | 가장자리 감광 ≤ 45% |
| Film Grain | 활성 | 프레임 간 화소 차 표준편차 ≤ 6 |
| Color Adjustments | 활성 (탁한 산업 팔레트로) | 채도 상승 금지 |
| Chromatic Aberration | **선택** | ≤ 0.15 — `VISUAL_SPEC` §8 「지속적 색수차는 피한다」 |
| Motion Blur / DoF | **금지** | 판독성 |

## G-7. 물리 — 「촉각」이 관측되는가

| 지표 | 통과선 |
|---|---|
| 물리로 구동되는 캐빈 오브젝트 종 수 | **≥ 6** (매달린 등·케이블·화물·고리·문 걸쇠·레버 반동) |
| 상승 가감속에서 반응하는 오브젝트 | **≥ 4종** |
| 사고(Collapse) 순간의 물리 반응 | 관측 가능 (연속 프레임에서 위치 변화) |
| **결정론 회귀** | 물리는 판정에 **영향을 주지 않는다** — 같은 시드가 같은 `SpinResult` |

마지막 줄이 이 축의 제약이다. `TECH_SPEC` 의 결정론 요구와 충돌하면 물리를 버린다.
물리는 **표현 계층에만** 산다.

## G-8. 성능 — 회귀 금지선

| 항목 | 현재 | 통과선 |
|---|---|---|
| GC Alloc / frame | **0 B** (`UP-TECH-04` VERIFIED) | **0 B 유지** |
| 측정 해상도 | 1920×1080 | 동일 |
| 프레임 시간 | 미고정 | 확대·텍스처 투입 후 **재측정하고 값을 고정한다** |

**`UP-TECH-04` 의 0 B 는 이번 작업이 깨뜨리기 가장 쉬운 것이다** —
텍스처 스트리밍, 파티클, 물리 콜백이 전부 할당원이다. 매 배치마다 재측정한다.

# 3. 통과 판정

| 게이트 | 조건 |
|---|---|
| **G-PASS** | G-1 ~ G-8 전부 통과선 충족 **그리고** 독립 시각 평가 판독성·스타일 **≥ 4.0** |
| **부분 통과** | 축별로 기록한다. 「G-1 통과 / G-4 미달」 같은 형태로 남긴다 |

**축이 통과선에 닿았는데 사람 평가가 여전히 REJECT 면 그것은 축이 틀린 것이다.**
그때는 축을 고치고, 고쳤다는 사실과 이유를 이 문서에 남긴다 —
숫자가 사람 판정을 대체하지 않는다. 숫자는 **인상 평가가 흔들릴 때 회귀를 잡는 것**이고,
`.claude/visual-criteria.md` 가 절대 점수를 금지한 이유가 그것이다.

# 4. 이 문서가 만들지 않는 것

- 폴리곤 예산 상향 — 로우폴리는 스타일 락이다
- PBR 금속·거칠기 워크플로 — `Ascend/Stylized` 는 비물리 셰이더이고 그대로 둔다
- 새 렌더 파이프라인·패키지 — `CURRENT_PHASE` §3 에 그대로 남아 있다
- 유료 에셋 — 텍스처는 전부 코드로 생성한다
