# −1. v6 개정 요약 (유지) — 마르코의 발견이 옳았다

마르코가 §14 명세를 독립 구현해 런 단위 수치 재현에 실패했고, 그 원인을 정확히 짚어냈다.
**재측정 결과 둘 다 그가 맞았다.**

## 발견 ① — 시뮬레이터가 명세를 위반하고 있었다

> *"§0.1의 운1 값(91.0% / 1.81줄)은 운 배치 후보에 **눈 칸을 포함**시켜야 재현된다.
> 명세대로 '눈이 아닌 칸'만 대상으로 하면 88.8% / 1.74다."*

**그의 수치가 정확히 재현됐다.** 운 배치 대상에서 **새로 뽑힌 눈까지** 제외하도록 고치자:

| 운 | 수정 전 (명세 위반) | 수정 후 (명세 충실) |
|---|---|---|
| 0 | 61.1% / 0.98줄 | **61.4% / 0.99줄** |
| 1 | 91.0% / 1.81줄 | **88.8% / 1.74줄** |

## 발견 ② — 기준 수치가 「신선판」 값이었다

> *"§3.4의 61.1%는 신선판 값이다. 눈이 칸을 점유하는 이 게임의 실전 값이 아니다.
> 실전 성립률은 **48.6%**, 평균 줄 0.74로 떨어진다. 이 게임의 자랑인 나선이
> 문서 자신의 기준 수치에 반영되어 있지 않다."*

**재측정: 실전 루프 48.2% / 0.73줄.** 그의 48.6% / 0.74와 오차 1% 이내다.
**이제 두 수치를 다 명기하고, 요구 공선은 실전 값 위에 얹는다.**

## 신규 규칙 — 남긴 스핀이 판을 닦는다

마르코의 네 번째 지적: *"§5.1의 '결정'은 층 중반부터 결정이 아니다. 5스핀 소진이
완주율 46.6%p 우위인데 1~6층은 눈도 층말 초기화되므로 **추가 스핀의 하방 자체가 없다.**"*

> **층이 끝날 때, 남긴 스핀 1회당 눈 하나가 닦인다. (7층 이상은 닦이지 않는다)**

이 한 줄로 세 가지가 동시에 풀린다:

1. **더 돌리면 실제 비용이 생긴다** — 실측 눈 3개+ 상태가 즉시확정 4.3% vs 5스핀소진 **7.4%**
2. **정책 격차가 좁혀졌다** — 39.1~78.4% → **39.0~64.0%**. 5스핀 정책의 2층 탈락이 3.0% → **8.1%**
3. **서리가 요구한 「누가 닦는가」에 답한다** — 닦는 것은 시간이 아니라 **쓰지 않은 스핀**이다.
   문을 일찍 닫으면 기계가 닦을 시간이 남는다. 스핀을 끝까지 쓰면 문이 그대로 닫힌다.

유인구는 이제 **트레이드오프**다 — 눈 가중치 +0.5, 눈 배수 −0.5. 자주 오지만 덜 준다.

## 2.3 눈의 규칙 — 정확히

```

1~6층                →  층이 끝날 때 남긴 스핀 1회당 눈 하나가 닦인다 (§5.1.1).
7~10층               →  🔴 닦이지 않는다. 전부 다음 층으로 넘어간다.
```

| 조건 | v5 판정 |
|---|---|
| ① 같은 난수가 이득과 손해를 동시에 배분 | **충족** — 눈 하나가 배수를 올리면서 칸 하나를 지운다 |
| ② 욕심의 레버 = 노출의 레버 | **충족** — 더 돌리기·눈 빌드·눈 방치 셋 다 노출을 늘린다 |
| ③ 비가역성 | **1~6층: 합성 충족** (눈 → 꽝 → 추락). **7층 이상·지하: 자체 충족** |

## 2.4 정본 독해 — 눈이 무슨 말을 하는가

서리: *"입은 만들었는데 무슨 말을 하는지 설계가 모른다. 설계가 소유하지 못한 진실은 버그다."*

| 규칙 | 정본 독해 |
|---|---|
| 눈은 전력을 만들지 않는다 | 연료의 경제 바깥에 있다. 기계의 회계에 안 잡히는 것이 목격자의 자격이다 |
| 눈이 있으면 배수 | **목격 프리미엄.** 보는 자 앞에서 성사된 납품은 값이 배가 된다 |
| 성립 줄 하나당 눈 하나 소멸 | **납품이 성공할 때마다 목격자가 하나씩 정리된다** |
| 1~6층 층말 초기화 | **누군가 판을 닦는다.** 초기화하는 주체가 있다는 뜻이다 |
| 7층 이상 초기화 없음 | 위로 갈수록 그 손이 게을러진다 |
| 눈은 각인·운·고정의 대상이 아니다 | **살아 있는 것은 낙인으로 찍어낼 수 없다** |

서리: *"이 두 예외 조항이 조용히 눈의 존재론을 완성한다."* — 정본으로 채택한다.
**고정 딱지도 눈에 붙지 않는다** (v4 미정의, 서리 권고 채택).

## 2.5 심볼 출처 — 내부 캐논 (UI 비노출)

| 심볼 | 내부 캐논 |
|---|---|
| 어금니 | 가장 오래 남는 부분. 그래서 가장 흔하다 |
| 뼈 | 형태가 남은 것 |
| 심장 | 아직 뛰던 것 |
| 눈 | 아직 보고 있는 것. **폐기된 「저항체」의 후계** |

**어떤 UI 텍스트도 심볼의 출처를 설명하지 않는다.**

# 3. 판정

```
① 여덟 줄을 본다. 어금니·뼈·심장 중 같은 것 셋이 선 줄이 성립한다.
② 줄 하나의 값 = 심볼값 × 그 줄의 줄값
③ 스핀 전력 = (성립한 모든 줄의 합) × 출력배수 × 눈배수^(판의 눈 개수)
④ 득점한 줄에 새김눈이 하나 생긴다 — 그 줄의 줄값 +1
⑤ 심볼은 사라지지 않는다. 판을 한 번 읽고 끝난다.
```

**연산 순서 (마르코 N5-④)**: 심볼값은 `기본값 + 장의사 배수 + 납추 가산` 순으로 확정한 뒤
줄값을 곱하고, 합산 후 출력배수, 마지막에 눈배수.

## 3.1 각인 — 운이 낀 줄에는 새김눈이 안 생긴다

> **운으로 강제된 칸이 하나라도 포함된 줄은 득점하되 새김눈을 남기지 않는다.**

마르코가 1차에서 예측한 문제("운이 다른 축의 발동 조건을 전부 켜 주는 마스터 스위치")를 실측으로 확인했다 —
운 빌드 959배 vs 개입 빌드 51배. 이 규칙으로 격차가 좁혀진다.
서사적으로도 맞다: **기계가 억지로 만든 줄은 자국을 남기지 않는다.**

## 3.1.1 도구로 만든 줄은 새김눈이 둘이다 — v6 신규

> **재추첨 또는 각인이 관여한 칸이 포함된 성립 줄은 새김눈이 +2 새겨진다.**
> **손으로 만든 것이 더 깊게 남는다.**

마르코의 v4·v5 지적("검역관·개입 동사의 한계 효용이 바닥이다")과 자체 U2 측정의 답이다.
개입 동사는 v5까지 **안정화 축**일 뿐 성장 축이 아니었고, 그래서 개입 빌드가 죽어 있었다.

| 빌드 (고정, +1스핀 정책, 1,500런) | 연결 전 | **연결 후** |
|---|---|---|
| 눈 빌드 (회수포+유인구+도박사) | 22.1% | **21.1%** |
| 줄 빌드 (결속선+납추+배관공) | 6.3% | 5.5% |
| **개입 빌드 (탐침+인두+광부+검역관)** | **1.4%** | **7.3%** |
| **아키타입 격차** | **16배** | **3.9배** |

정민아의 U2 목표(2배 이내)에는 아직 못 미친다. **U2로 계속 남긴다.**
단 이 측정은 **1층부터 고정 빌드**를 가정한 것이라 실제 드래프트 진행과 다르다는 한계가 있다.

## 3.2 표시 — 이산 새김눈

이서진: *"각인은 +1씩 쌓이는 정수인데 표현은 아날로그(깊이·밝기)다. 8줄이 한 유리판 위에서
교차하는데 깊이를 상호 비교하는 과제는 지각적으로 의심스럽다."*

**→ 홈 깊이가 아니라 새김눈 개수다.** 각인 1회 = 홈에 새김눈 하나. 다섯 개마다 묶음 빗금.
개수는 셀 수 있고 깊이는 못 잰다. 상한 없는 값 문제도 묶음 표기로 자연 확장된다.

## 3.3 층 정산

> **층을 통과할 때, 그 층에서 선 줄 하나당 출력배수가 4% 오른다. (곱셈)**

이것이 §5.1의 결정을 살린다 — 더 돌리면 줄이 더 서고, 출력이 영구히 오른다.

## 3.4 기준 수치 — 두 체제를 구분해 적는다

> 마르코: *"문서의 61.1%는 **신선판** 값이다. 눈이 칸을 점유하는 이 게임의 **실전** 값이 아니다."*
> → **둘 다 적는다. 요구 공선은 실전 값 위에 얹는다.**

| 지표 | **신선판** (잔류 눈 0, 도구 없음) | **실전 루프** (5스핀 층, 눈 점유 포함) |
|---|---|---|
| 성립률 (운 0) | **61.4%** | **48.2%** |
| 평균 성립 줄 | **0.99** | **0.73** |
| 성립률 (운 1, 교습 보정) | **88.8%** | **82.0%** |
| 판의 눈 3개 이상 | — | **14.4%** |
| 5스핀 전멸률 (운 0) | — | **11.2%** |

실전과 신선판의 차이(61.4% → 48.2%)가 곳 **눈이 칸을 먹어 만드는 나선**이다.
그 나선은 이제 문서의 기준 수치에 반영되어 있다.

**1층 5스핀 전력 중앙값: 470** (교습 보정 운 1, 승객·부품 없음)
> 마르코 독립 재현 490~510과 **편차 −6%**. ±10% 밴드 안에 들어왔다.
> **눈 3개 이상 지표는 「스핀 시작 시점의 잔류 눈」 기준이다.**

## 3.5 판정 시점

```
판이 멈춘다 → 전력이 계기에 즉시 표시된다 (아직 가산 안 됨)
→ 개입하면 계기 숫자가 실시간으로 다시 계산된다
→ 다음 레버 또는 확정을 누르는 순간 가산된다
```
개입으로 새로 선 줄의 새김눈과 눈 소멸도 **가산 시점에** 확정된다.

# 4. 운

> **운 N = 판이 멈추기 전에 눈이 아닌 칸 N개를 같은 심볼로 바꾼다.**
> **기본 운 0.** 1~2층만 교습 보정으로 1.

## 4.1 배치 = 전역 최적 (완전 명세)

```
후보: 잔류 눈이 아닌 칸 전체
N칸 조합을 전수 탐색 (최대 C(9,5)=126)
1순위: 성립 줄 수 최대
2순위: 성립 줄의 심볼값 합 최대     ← 마르코 N5-⑥ (뼈줄과 심장줄이 동수일 때)
3순위: 칸 인덱스 오름차순
강제 심볼은 줄 형성 3종의 가중치로 추첨. 동점 시 인덱스 낮은 심볼   ← 마르코 N5-⑤
```
**완전 결정적이라 시드 재현이 유지된다.**

## 4.2 개입 동사 3종 — 도구를 먼저 집는다

| 동사 | 도구 | 언제 | 무엇을 | 눈에 |
|---|---|---|---|---|
| **고정** | 봉인 딱지 | 스핀 전 | 칸 하나를 이번 스핀에 다시 뽑지 않는다 | **불가** |
| **재추첨** | 곡괭이 | 판 정지 후 | 칸 하나를 깨서 다시 뽑는다 | **가능** |
| **각인** | 낙인 인두 | 판 정지 후 | 칸 하나를 지정 심볼로 (헤드 3개) | **불가** |

- 도구를 집으면 **조준 칸이 하이라이트**되고, 클릭 후 **0.3초 홀드**로 발동한다 (오발 방지)
- 도구를 놓으면 취소. 스핀 전 창은 레버를 당기는 순간 닫힌다
- **위상 밖 도구는 랙에서 뽑히지 않는다**
- 눈에 안 되는 도구를 눈 칸에 대면 **미끄러진다**

# 5. 층 하나의 흐름

```
1. 문이 열린다 — 요구 전력·남은 스핀·후보 승객 2명
2. 승객을 태운다 (또는 둘 다 거절). 무게만큼 요구 전력이 오르고 경보가 운다
3. 정비권이 있으면 부품을 산다
4. (도구) 고정할 칸을 정한다
5. 레버 → 판 정지 → 계기에 전력 표시
6. (도구) 칸을 만진다 → 숫자가 바뀐다
7. 다음 레버 또는 확정
8. 층 정산 (문이 닫힌 뒤, 통제 불가 구간에서)
```

## 5.1 유일한 결정

| 지금 확정 | 더 돌린다 |
|---|---|
| 남은 스핀 1회당 **정비권 1장** (최소 1장 보장) | 줄이 더 서면 **출력배수 영구 상승** |
| | 눈이 더 쌓인다 (배수이자 위험) |

## 5.1.1 확정은 판을 닦는다 — v6 신규

> **층이 끝날 때, 남긴 스핀 1회당 눈 하나가 닦인다. 7층 이상은 닦이지 않는다.**

마르코: *"1~6층은 눈도 층말 초기화되므로 **추가 스핀의 하방 자체가 없다.**
'유일한 결정'이 실은 지배당한 결정이다."*

→ 이제 하방이 있다. 더 돌릴수록 눈이 다음 층으로 넘어간다.
서사도 정확해졌다 — **닦는 것은 시간이 아니라 쓰지 않은 스핀이다.**

**실측 (각 4,000런 · §14 + §14.1 명세 충실)**

| 정책 | 완주율 | 눈 3개+ 상태 스핀 | 2층 탈락률 |
|---|---|---|---|
| 요구 달성 즉시 확정 | **25.4%** | **10.6%** | 2.8% |
| +1스핀 더 | **36.7%** | 11.1% | 3.5% |
| 항상 5스핀 소진 | **41.3%** | **16.2%** | **12.7%** |

**격차 15.9%p.** 신규 규칙 전엔 5스핀 소진이 일방적으로 우월했다.
이제 5스핀 소진은 완주율은 높지만 **눈을 1.7배 더 쌌고, 2층에서 2.7배 더 죽는다.**

## 5.2 과부하 보정 — 기계의 식욕

```
긴급도 = (요구 − 현재) / 요구 / 남은 스핀
<0.35 없음 │ ~0.60 운+1 │ ~0.90 운+2 │ ~1.40 운+3 │ 이상 운+4
```
**구제 연출이 아니라 개입 연출이다.** 건물이 네가 떨어지는 것을 원치 않는다. 위에서 기다리고 있기 때문이다.

## 7.1 되먹임 의존도 — 로그 분해로 재계산

마르코와 정민아가 **독립적으로 같은 지적**을 했다.

> 마르코: *"(7366−900)/7366 = 87.8%는 곱셈 인자들을 덧셈으로 분해한 값이다.
> 성장 기여는 **로그 공간에서** 재야 한다."*
> 정민아: *"곱셈 게임에서 의미 있는 척도로는 이미 내 70%대 목표를 통과한다.
> **문서가 이 계산을 안 한 것은 손해다.**"*

**v6 실측 (양방향 절제, 각 600런 · §14.1 명세 충실)**

| | 총 성장 | 자릿수 |
|---|---|---|
| 되먹임 둘 다 켬 | **876배** | 2.94 |
| 되먹임 둘 다 끔 | **18배** | 1.26 |

- 선형 분해(잘못된 셈): 97.9%
- **로그 분해(올바른 셈): 57.1%** ← 정민아 목표(70%대) 통과

**U1을 닫는다.** 다만 재해석("되먹임은 빌드 분기가 아니라 모든 빌드의 공통 기반")은 유지한다 —

## 8.5 하차 = 납품

> 승객은 목적지 층에서 **인도된다.** 기계가 운영자에게 **인도 완료 수수료**를 지불한다.
> **정비권 = 태우고 지나온 층 수. 최대 3장.**

서리: *"운임이 운송 거리에 비례한다. **요금 체계 자체가 화물 운송임을 자백한다.**"*

### 붙잡기 = 억류

문이 열릴 때 막으면 남는다. **무게 +2, 효과 절반, 인도 수수료 영구 소멸.**
붙잡힌 승객은 그 순간부터 말을 하지 않는다.

**억류의 종결 (서리 미비 지적)**: 억류한 층으로부터 **3층을 더 지나면 소진되어 사라진다.**
수수료는 없다. 소진된 자리는 비어 있다.

**두 침묵의 구별**: 억류된 자만이 **문이 열릴 때마다 문 쪽을 본다.** (§10.5의 침묵과 구별)

## 8.6 내부 전용 어휘 — 표면 노출 금지

`납품` `억류` `조달` `기계의 식욕` `목격 프리미엄` `목격자 정리` `수확` `영혼`

UI·툴팁·업적명·패치노트에 쓰지 않는다. §6.3 교습표의 "하차(납품)" 괄호도 내부 문서 전용이다.

# 11. 리텐션 — 2축 + 서사 장치 1

> 정민아: *"인도 기록부는 1회성 컴플리션 체크리스트다. **정확히 CloverPit이 하나 들고 있다가

> **→ 셈에서 뺀다. 서사 장치로만 유지한다.**

## 11.1 축 1 — 하강

10층을 완주하면 엘리베이터가 내려간다. **지하에서는 눈이 초기화되지 않는다.**

### 정본 독해 — 하강은 조달 회송 운행이다

서리: *"규칙이 또 세 번 자백한다. ① 하강은 납품 완료 후 시작된다 — 빈 화물칸이 어디로 가는가.
② 하강 깊이가 명부를 늘린다 — 이건 언락 편의가 아니라 **조달**이다. 아래는 화물의 산지다.
③ 지하에는 판을 닦는 손이 닿지 않는다 — **정화 설비가 없는 가공 전 구역**이다."*

> **상승은 강요된 노동이고, 하강은 플레이어가 스스로 선택하는 유일한 방향이다.**
> 이 게임의 스코어는 최고층이 아니라 **최저층**이다. 신은 올라오라 하고, 플레이어는 내려간 깊이로 기록된다.

**지하의 종말 = 시선의 포화.** 케이블이 끊어져 끝나지 않는다. **눈이 판을 다 덮어서,
줄을 세울 자리가 없어져서 끝난다.** 상승의 실패는 추락이고 하강의 실패는 포화다.

### 포화 수학 (정민아 요구)

관측: 눈 3개가 대각선을 이루면 8줄 전부가 차단된다(2/84 경우). 눈 7개 이상이면 그 층은 수학적 사망.
기본 상태 전줄 차단은 스핀의 1.9%, 눈 풀빌드에서 10.4%.

**→ 지하 완화 규칙: 층을 통과할 때마다 눈 하나가 정화된다.** 포화가 단조 증가에서
"유입 vs 정화" 균형으로 바뀌어 곡괭이 필수 수렴을 막는다. **정확한 도달 깊이 분포는 미측정 — U1로 남긴다.**

**비교 표면**: 최저층 기록은 **주간 시드 리더보드**로 공개한다. 혼자 보는 숫자는 축이 아니다.

```
눈 배수     2.0 + 회수포 0.5 + 도박사 0.5 − 유인구 0.5,  상한 3.0

층당 스핀   5

스핀:
  잔류 눈을 판에 배치 → 나머지 칸을 가중치 추첨
  운 N: 눈 아닌 칸에서 N칸 조합 전수 탐색 (1순위 줄 수, 2순위 심볼값 합, 3순위 인덱스)

  8줄 판정 → 줄값 = 심볼값 × 줄값, 합산
  전력 = 합 × 출력배수 × 눈배수^눈개수
  성립 줄 줄값: 도구(재추첨·각인) 칸 포함 시 **+2** > 운 강제 칸 포함 시 **+0** > 그 외 **+1**
  압력 밸브: 3줄 이상이면 출력배수 +0.5
  눈 소멸: 성립 줄 수만큼, 가장 오래된 것부터

층 시작:  하차 정산 → 승객 드래프트(자리<4) → 부품 구매(자리<3, 재구매 불가)
층 종료:  출력배수 ×= (1 + 0.04 × 층 성립 줄 수);  정비권 += max(1, 5−사용 스핀)
층말 눈 청소: 1~6층 = 남긴 스핀 1회당 눈 1개 소멸 / 7~10층 = 청소 없음
과부하:   긴급도 = (요구−현재)/요구/남은스핀 → 운 +0~4
```
