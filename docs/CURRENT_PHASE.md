이 문서는 현재 자율 개발 세션에서 허용되는 범위를 제한한다. 전체 제품 범위는 `MASTER_PRD.md`가 정의하지만, 이번 세션에서는 아래 항목만 완료 대상으로 삼는다.

# 1. 세션 목표

결정론적 룰렛 코어와 1층짜리 플레이 가능한 Hero Slice를 완성한다.

플레이어가 다음 흐름을 개발자 개입 없이 경험할 수 있어야 한다.

`계약 선택 → 실행 레버 → 3×3 결과 공개 → 정화·패턴·캐스케이드 → 전력 획득 → 요구 전력 달성 → 확정 또는 과수확 선택 → 결과 확인`

# 2. 구현 대상

## 2.1 결정론적 코어

- 시드 기반 3×3 보드 생성
- 정상 영혼 1종
- 흡수체 1종
- 증식체 1종
- 흡수체 계약
- 증식체 계약
- 같은 저항체 3개 이상 기본 정화
- 가로·세로·대각선 직선 3개 판정
- 직교 연결 4개 이상 판정
- 제거, 빈칸 충전, 재판정
- 캐스케이드 하드 캡 20회
- 흡수체 잔류 전력 감소
- 증식체 잔류 가중치 증가
- 전력과 요구 전력 판정
- 재현 가능한 `SpinResult`

## 2.2 플레이 가능한 1층 Hero Slice

- 현재 `Prototype_Elevator.unity` 씬 사용
- 1인칭 이동과 시점
- 계약 선택 인터페이스
- 실행 레버
- 세 통관 또는 3×3 결과 표현
- 전력 계기판
- 남은 스핀 표시
- 요구 전력 달성 상태
- 전력 확정 상호작용
- 과수확 레버 잠금·해제와 선택
- Stable 상태
- Critical 상태
- 1층 성공, 실패 또는 사고 결과
- 최소 사고 기록 요약

## 2.3 테스트와 증거

- 핵심 EditMode 테스트
- 핵심 PlayMode 테스트
- 고정 시드 최소 3개
- Stable 캡처
- Critical 캡처
- 과수확 접근 캡처
- 5연쇄 이상 캡처 또는 이를 재현하는 테스트 시드
- 테스트 결과 요약
- 치명적 콘솔 오류 목록
- Windows 실행 빌드 또는 빌드 차단 원인

# 5. 통과 게이트

## Gate A — 코어

- Unity 씬 없이 핵심 판정 테스트가 통과한다.
- 동일 시드가 동일 결과를 재현한다.
- 캐스케이드가 20회를 초과하지 않는다.

## Gate B — 플레이 흐름

- 계약 미선택 상태에서는 스핀할 수 없다.
- 레버 한 번으로 결과 공개와 판정이 완료된다.
- 중복 입력으로 상태가 손상되지 않는다.
- 요구 전력 달성 후 확정 또는 과수확을 선택할 수 있다.
- 디버그 조작 없이 1층을 종료할 수 있다.

## Gate C — 판독성과 위험

- 정상 영혼, 흡수체, 증식체를 1초 안에 구분할 수 있다.
- 정화와 캐스케이드 원인을 따라갈 수 있다.
- Stable과 Critical 상태가 무음 캡처에서도 구분된다.
- 과수확 레버가 일반 실행 레버와 혼동되지 않는다.

## Gate D — 기술 증거

- 치명적 콘솔 오류가 없다.
- 테스트 결과와 재현 시드가 저장된다.
- 캡처와 성능 측정 결과가 제출된다.
- 미완료와 승인 대기 항목을 숨기지 않는다.

# 6. 중단 규칙

- Gate A가 통과하기 전 비주얼 대규모 폴리시를 시작하지 않는다.
- Gate B가 통과하기 전 10층 확장을 시작하지 않는다.
- 빌드가 깨진 상태에서 새 기능을 추가하지 않는다.
- 동일 오류를 세 번 반복하면 최소 재현 테스트 또는 격리 전략으로 전환한다.
- 사용자 승인 없이 이 문서의 제외 항목을 현재 범위로 승격하지 않는다.
