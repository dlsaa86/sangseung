## 1. 공간 미학 목표 (확정)

- **좁고 높고 박스형**이며 실제로 작동할 것 같은 구조
- 장식보다 **기능과 마모**가 먼저 보인다
- 플레이어·승객·화물이 늘어날수록 **공간 밀도가 높아진다**
- 룰렛 기계·계약 패널·전력 계기판·과수확 레버가 **실루엣만으로 구분**된다
- 문 밖은 짧고 어두운 공간으로 **호기심과 위협만** 제공하며 핵심 루프를 지연시키지 않는다

| **벽면** | 계약 패널 / 인쇄된 계약서 / 봉인된 표식 | 층 시작 계약 선택 |
| **NPC 배치 벽** | 승객 4명의 실제 서 있는 위치 | 승객 확인·반응 관찰 |
| **선반·고정대·장치 접속부** | 장착 아이템 3개, 화물 | 빌드 구성 |
| **전력 탱크 주변** | 전력 탱크, 오염 계기판 | 현재 전력·요구 전력·초과 임계점·잔류 위험 |
| **문 밖** | 짧은 복도 또는 방 | 승객 발견, 계약·아이템 획득, 괴담 관찰 |

**계약의 물리적 제시 형태는 3안 중 미결** — 벽면 계약 패널 / 인쇄된 계약서 / 봉인된 표식.

## 4. 플레이어 동선 원칙 (확정 — 전부 금지형)

| 원칙 | 원문 |
|---|---|
| **왕복 노동 금지** | 반복 스핀마다 장치 사이를 길게 왕복하게 하지 않는다. 이동은 몰입과 선택을 만들되 **반복 노동이 되어서는 안 된다** |
| **위치 종속 정보 금지** | 중요한 결과를 특정 위치에서만 볼 수 있게 하지 않는다. **플레이어가 등을 돌려도** 사운드·점등·보조 UI로 결과와 전력 변화를 파악할 수 있어야 한다 |
| **접근 차단 금지** | 엘리베이터는 좁고 압박감 있어야 하지만 플레이어·승객·화물이 서로 끼어 **핵심 장치에 접근하지 못하는 상황은 만들지 않는다** |
| **시선 높이** | 핵심 상호작용물은 자연스러운 시선 높이와 이동 동선에 배치하고, 어두운 공포 연출 속에서도 **형태·조명·소리로 찾을 수 있어야** 한다 |
| **루프 지연 금지** | 문 밖 공간이 **핵심 룰렛 루프를 과도하게 지연시키지 않는다** |

## 5. 1인칭 가독성 기준 (확정)

- 모든 Context Image는 **플레이어 눈높이 1인칭 카메라 시점도 별도 제작**한다
- 한 시점 안에서 **실행 레버 · 3×3 결과창 · 전력 탱크 · 계약 장치**가 서로 구분되어야 한다
- 장치 앞에 섰을 때 **핵심 결과가 잘리지 않고**, 한두 걸음 물러나면 **전체 기계와 승객을 함께** 읽을 수 있어야 한다
- 문 밖 복도·방은 짧은 탐색용이며 **엘리베이터로 돌아오는 방향이 조명과 구조로 즉시 읽혀야** 한다

### 5.1 1인칭 시야 우선순위 (중요 오브젝트)

1. **3×3 결과판** — 판정 결과
2. **실행 레버 (2단 통합)** — 유일한 실행 입력
3. **전력 탱크 / 계기판** — 현재 전력 vs 요구 전력, 초과 임계점
4. **전력 확정 브레이크** — 안전 종료
5. **계약 패널** — 층 시작 선택
6. **승객 4명** — 반응과 빌드 상태
7. **오염 계기판** — 잔류 저항 위험
8. 층수 표시기
9. 화물·아이템 선반
10. 소품·장식

> 🔴 이 순위는 검증 실패의 진단 기준이다. 현재 **1위·2위·3위가 동시에 보이는 캡처 지점이 없고**,
> 레버 앞에서 결과판이 사라지는 문제가 미해결이다 → [CURRENT_STATE.md](CURRENT_STATE.md).

## 7. 문 밖 공간

### 7.1 역할 (후보)

- **짧은 탐색, 승객 발견, 계약·아이템 획득, 괴담 관찰**
- 문이 열리며 1인칭으로 확인할 수 있는 짧은 공간과 장면 제시
- 테마 전환 요소에 포함 (조명과 문 밖 환경)
- 위험 신호로 사용 — "제한 임박: 문 밖의 소리, 경고등"

### 7.2 제약 (확정)

**깊이 3~5m의 작은 무대로 제한한다.** (세 비주얼 문서 중 유일한 치수 규정 두 개 중 하나)

구성: 바닥·벽·천장 모듈 / 막힌 통로 또는 외부 문 / 천장 조명과 층 번호 / 배관·전선·상자·폐기물.

**문 밖 공간의 이동 시간·허용 오브젝트 수는 미명시.** *"제한된 공간"*, *"짧은 탐색"*이 전부다.

## 8. 층 구조와 테마

### 8.1 테마 재사용 원칙 (확정 — 즉시 적용 가능)

> 각 층마다 새로운 배경을 만들지 않는다. 일정 구간에서는 **모듈형 배경을 재조합**하고
> 큰 마일스톤에서만 시각·음향·저항 규칙을 전환한다.

| 마일스톤 | 내용 | 프로토타입 |
|---|---|---|
| 1층대 | **밑바닥·폐쇄된 지하 시설** | ✅ 1~10층의 유일한 테마 근거 |
| 10층 진입 | 첫 번째 테마 전환 | ⚠ 경계 — 10층 보스와 겹침 |
| 100 / 200 / 500층 | 대규모 전환 | ❌ 범위 밖 |

### 8.2 한 층의 페이싱 4단계 (후보)

준비(요구 전력·스핀 수 확인, 계약 비교, 발동 순서 확인) → 초반 스핀(안정화) →
중반 스핀(빌드 발동) → 종반(확정과 욕심).

**각 단계의 스핀 수 배분은 미명시.**

### 8.3 일반 층의 역할 (후보)

문이 열리며 짧은 공간과 장면 제시 / 승객 또는 위협 등장 /
클릭해 확인·획득·계약할 수 있는 아이템과 장치 배치 / 아이템과 거래 /
저항 계약 선택 / 요구 전력·스핀 수·심볼 풀 변화 / 특수 층·보스 사전 경고 /
긴장 이후 수리·정리·빌드 재구성.

## 11. 위험 단계의 공간 표현 (확정)

| 단계 | 공간에서 일어나는 일 |
|---|---|
| **Stable** | 따뜻하고 희미한 기본 조명 / 일정한 모터음과 미세 진동 / 계기판 바늘 안정 / 승객 중립 대기 |
| **Strain** | 천장등이 짧게 어두워짐 / 간헐적 낮은 `쿵`과 바닥 진동 / 바늘 미세 진동 / **천장 먼지와 녹가루** / 승객 한 명이 위 또는 벽을 바라봄 |
| **Critical** | 일반 조명 일부 소등, **회전식 붉은 비상등** / 저주파 `쿠웅` 간격 단축 / 문과 철판 미세 떨림 / **화물과 매달린 부품이 흔들림** / 짧은 수직 낙하 충격 / 승객이 난간을 붙잡고 플레이어를 바라봄 |
| **Collapse** | 사이렌·모터 끊김 → **0.3~0.7초 암전과 정적** → 거대한 금속 파열음 → 급강하 또는 강한 제동 → 붉은 비상등 불규칙 재점등 → 화물·승객의 물리적 반응 |

**연출 원칙 (확정)**
- 사이렌은 **지속 재생하지 않는다.** 단계 상승·과수확 해금·레버 결정·사고 순간에만
- 지속 위험은 저주파·금속 응력음·짧은 진동으로 유지
- **카메라 셰이크보다 환경 오브젝트와 승객을 우선 흔든다**
- **기본 상태가 충분히 안정적이어야 위험 변화가 읽힌다**

## 13. 금지 (공간 한정)

- 벽에 불필요한 그림·그래피티·**읽을 수 없는 장식용 텍스트**
- 선반을 불필요한 상자로 채우기 — 선반은 **기능적인 아이템 공간**이다
- 명확한 게임플레이 기능이 없는 **별도 전력 계기판이나 콘솔**
- 핵심 장치 이외의 기계 (최소화)
- **플레이 공간을 침범하는 장식물**
- 결과판보다 눈에 띄는 장식
- 장식용 버튼과 실제 클릭 대상을 혼동시키는 **기능 없는 미세 조작부**
- 별도의 균형추·투명 관측창·안전핀 장치

> **오래되고 투박한 외형**과 **구조적으로 말이 되지 않는 디자인**을 혼동하지 않는다.
> 플레이어가 다음 행동을 **환경의 구조만 보고 추론**할 수 있어야 한다.
