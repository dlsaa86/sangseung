# 요구사항 누락 감사 — 백로그에 **없는** 것 (2026-08-02)

> 지금까지의 모든 감사는 「백로그 항목이 구현됐는가」를 물었다.
> 이 감사는 **반대**를 묻는다 — **백로그에 아예 없는 요구가 있는가.**
>
> 수행: 독립 읽기 전용 감사자 (구현자와 분리). 파일 수정 0건.
> 원 산출물은 임시 워크플로 출력에만 있었으므로 여기 옮겨 보존한다.

## 0. 먼저 — 이 감사가 발견한 가장 큰 구조적 결함

**백로그의 `출처: PRD §…` 표기는 `docs/MASTER_PRD.md` 를 가리키지 않는다.** 두 개의 서로 다른 절 번호 체계가 섞여 있다.

| 백로그가 쓰는 번호 | 동결 `docs/MASTER_PRD.md` 의 실제 §번호 | 근거 |
|---|---|---|
| §15.1 필수 캡처 | §11 | `NotionSyncReport.md:94` |
| §17 Definition of Done | §13.1~13.5 | `:96` |
| §18 Phase 1~6 | §14 | `:97` |
| §21 에이전트 시작 | §15 | `:98` |
| §8.x 위험 상태 | §9 | 백로그 `UP-DOC-02` 스스로 인정 (`:1563`) |
| §10.3 · §13.x · §14.1 · §16.2 · §24 · §25 | **동결 PRD 에 존재하지 않는다** | `UP-REC-03` 스스로 인정 (`:1163`) |

동결 스냅샷은 Notion PRD 의 **축약 재작성**이다. 결과:

1. 백로그 129건 중 **다수의 유일한 PRD 근거가 동결 PRD 에 없는 절**이다(`§7.3`·`§7.4`·`§9.2`·`§9.3`·`§9.4`·`§10.2`·`§10.3`·`§12.1~12.5`·`§13.1~13.5`·`§14.1`·`§16.2`). 백로그 §0.2 는 "Required 는 PRD §4.1/§13/§15/§17 에서만 나온다"고 선언하는데, 그 §번호들이 동결 문서에 없으므로 **분류 규칙이 자기 근거를 대조할 수 없다.**
2. 반대로 동결 PRD 에만 있는 문장(§6.1 판독 순서, §12 플레이테스트 지표, §14 Phase 6 통과 조건)은 백로그가 **한 번도 인용하지 않는다.**
3. `CLAUDE.md` 는 "동결 `docs/` 스냅샷을 기준으로 한다"고 명령하는데, 백로그는 Notion 번호로 적혀 있어 **어느 감사자도 기계적으로 대조할 수 없다.**

이것이 아래 「백로그에 없음」 항목들이 지금까지 발견되지 않은 이유다.
