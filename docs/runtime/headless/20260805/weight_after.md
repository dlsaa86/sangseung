## 기울기 — 선형인가 계단인가

| 구간 | 무게당 완주율 변화 (%p / 무게10) |
|---|---:|
| 0 → 10 | -3.18 |
| 10 → 20 | -3.50 |
| 20 → 30 | -2.70 |
| 30 → 40 | -2.65 |
| 40 → 50 | -2.50 |
| 50 → 60 | -2.25 |
| 60 → 70 | -1.95 |
| 70 → 80 | -2.08 |
| 80 → 100 | -0.86 |
| 100 → 120 | -0.30 |
| 120 → 150 | +0.00 |
| 150 → 200 | +0.00 |

> **읽는 법.** 기울기가 구간 내내 비슷하면 대가는 **선형**이고,
> 「조금 더 실으면 조금 더 나빠진다」뿐이라 결정을 만들지 못한다.
> 어느 구간에서 기울기가 급변하면 그 지점이 **문턱**이고, 그때는
> 실제 적재가 그 문턱에 **닿는지**가 다음 질문이 된다.
