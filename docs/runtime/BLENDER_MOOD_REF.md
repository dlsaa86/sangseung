## 3. 휘도 비율 분석

### 계산 방식

표준 상대 휘도 공식 (ITU-R BT.709):
```
L = 0.2126×R + 0.7152×G + 0.0722×B
```

### 결과

| 항목 | RGB | 휘도 | 리세스 대비 |
|---|---|---|---|
| **벽** | (0.8, 0.8, 0.8) | **0.8000** | 1.0 (기준) |
| **리세스** | (0.0460, 0.0430, 0.0380) | **0.0433** | **0.0541** |

### 해석

- **현재 상태:** 리세스가 벽 밝기의 **5.41%만 차지** (약 18.5배 어두움)
- **사용자 평가:** "너무 진함"
- **원인:** 극도로 낮은 휘도 → 색감 감지 어려움 + 회색처럼 보임

---

## 4. 채도 비교 (HSV)

### 계산 방식

HSV 채도: S = (Max - Min) / Max

### 결과

| 항목 | 채도 | 색감 |
|---|---|---|
| **벽** | 0% | 순수 그레이 (색감 없음) |
| **리세스** | 17.39% | 갈색/노란색 톤 (따뜻함) |

### 해석

- 벽은 의도적인 중성 그레이
- 리세스는 갈색 톤을 가지고 있으나, 극도로 어두워서 **색감이 시각적으로 약함**
- 사용자 지적 "채도도 없고 흐려 보임" ← 절대 밝기 문제가 채도 인식을 가림

## 5. 조명 환경

### LT_CabBulb (주조명)

- **타입:** POINT
- **에너지:** 52.0
- **색:** `(1.0, 0.82, 0.50)`
- **특성:** 따뜻한 백열등 / 색온도 ~3000K
- **영향:** 기계 둘레를 주로 비추고 어두운 부분을 더욱 검게 만듦

### LT_SoulSpill (보조조명)

- **타입:** POINT
- **에너지:** 13.0
- **색:** `(1.0, 0.42, 0.22)`
- **특성:** 극도로 따뜻한 톤 / 색온도 ~2000K
- **영향:** 시각적 온기 강조, 어두운 표면의 채도 조건을 더욱 엄격하게 함

### 조명의 영향

강한 따뜻한 조명(특히 저색온도 2000K) 환경에서:
- 어두운 표면(낮은 휘도)이 더 검게 보임
- 채도 변화에 덜 민감함
- 중간톤의 중요성 증가

## 6. 월드 설정

### 배경

- **배경색:** `(0.014, 0.011, 0.009)`
- **배경 휘도:** 0.0120
- **배경 톤:** 따뜻한 갈색 (거의 검은색)
- **배경 세기:** 1.0

### 특성

배경이 가까운 검은색이므로, 패널 리세스와의 명도 대비가 매우 약함 → 경계가 뭉개져 보일 수 있음

---

## 7. 렌더 설정

| 항목 | 값 | 의미 |
|---|---|---|
| **View Transform** | AgX | Khronos 표준 tone mapping (현대적 색감 재현) |
| **Look** | None | 추가 색감 프로필 없음 |
| **Exposure** | 2.3 | +2.3스탑 (밝기 상향 5.13배) |
| **Gamma** | 1.0 | 선형 (감마 보정 없음) |

### AgX의 특성

- 어두운 값들(특히 0~0.1 범위)에 강한 compression 적용
- 극저휘도 표면에서 색감이 소실되기 쉬움
- Exposure 2.3은 충분하지만, 휘도 0.0433는 여전히 매우 낮음

## 8. 결론 및 해석

### 현재 상황 요약

| 지표 | 값 | 평가 |
|---|---|---|
| 리세스/벽 휘도비 | 0.0541 | 너무 낮음 (목표 0.25~0.35에 비해) |
| 채도 차이 | 17.4% vs 0% | 채도는 충분하나 인식 못함 |
| 조명 톤 | 따뜻한 2000~3000K | 어두운 표면을 더욱 검게 강조 |
| Tone mapping | AgX + Exposure 2.3 | 극저휘도에 압축 강함 |

### 사용자 요구 해석

**원문:** "검은색이 너무 진한 게 문제였지 적당히 진해야지. **벽색보다 조금 진한 정도.**"

**해석:**
- 현재: 벽의 5.4%만 밝음 (거의 검은색)
- 요구: 벽보다 "조금 진한 정도" = 벽의 약 60~75% 밝기 = **휘도비 0.25~0.35**

## 9. 개선 방향

### 권장 액션

1. **M_Elev_DarkIron Base Color 상향 조정**
   - 현재: RGB `(0.0460, 0.0430, 0.0380)` → L = 0.0433
   - 목표: L = 0.2000~0.2500 (휘도비 0.25~0.31)
   - **제안값:** RGB `(0.15, 0.14, 0.12)` ~ `(0.19, 0.18, 0.15)`
   - 상향폭: 약 2.7~3.5배

2. **채도 검토**
   - 현재 17.4%의 갈색 톤은 유지 권장 (따뜻한 조명과 조화)
   - 색 보정 후 시각 확인 필요

3. **검증 절차**
   - 변경 후 AgX + Exposure 2.3 환경에서 스크린샷
   - 벽(M_Cab_Wall)과 직접 비교
   - "벽색보다 조금 진한 정도"인지 사용자 확인
