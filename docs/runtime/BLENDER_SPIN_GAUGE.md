## 2. 게이지 설계

### 스핀 횟수 (최대값 확인)

**출처:** `Assets/Prototype_Elevator/Scripts/Spin/FloorPlan.cs`

```csharp
Spins = 5,  // 모든 층에서 고정
```

**확인:** 모든 플로어의 기본값이 5로 일정함.  
**게이지 칸 수:** `5칸`

### 기존 게이지 패턴 (참고)

- **하우징 머티리얼:** `M_Elev_FrameSteel` (어두운 강철)
- **칸 머티리얼:** `M_Elev_GaugeFill` (주황색 발광)
- **예시:** `SM_Gauge_Housing` + `SM_Gauge_<여러칸>`

### 설계 제약

- **로우폴리**: 칸 하나당 상자 1개, 전체 200 tri 이하
- **칸 개별 오브젝트**: 유니티에서 켜고 끔 → 각각 별도 메시
- **머티리얼 재사용**: 새 머티리얼 금지

## 3. 위치 결정

### 게이지 배치 계획

| 항목 | 값 |
|---|---|
| **Z 하단** | 1.7000 (손잡이 윗면 1.6791 + 여유 0.0209) |
| **Z 상단** | 1.9300 (베이 탑 1.9488 - 여유 0.0188) |
| **사용 가능 높이** | 1.9300 - 1.7000 = 0.2300 |
| **구성** | 하우징(0.05) + 칸 5개(0.04 × 5) + 여백 |

### 중심선 (X, Y)

손잡이들 중앙을 목표:
- **X 중심:** (0.612 + 0.8738) / 2 ≈ 0.7429
- **Y 중심:** (2.8019 + 2.9303) / 2 ≈ 2.8661

또는 베이 중심 사용:
- **X 중심:** (0.5032 + 0.9247) / 2 = 0.7140
- **Y 중심:** (2.8019 + 2.9303) / 2 = 2.8661

**결정:** 베이 중심 기준으로 배치
