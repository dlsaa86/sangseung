# 전력 게이지 모델링 실측

**측정 일자**: 2026-08-08  
**측정 도구**: blender_bridge.py + Blender MCP  
**파일**: 현재 열린 .blend (Upandup_DDD 엘리베이터 게이지)

## 1. 찾은 오브젝트 전수 목록과 실측 치수

### 1.1 게이지 구성 메시

| 오브젝트 이름 | 타입 | 월드 X (min) | 월드 X (max) | 월드 폭 | 부모 | 역할 |
|---|---|---|---|---|---|---|
| `SM_Gauge_Fill` | MESH | -0.7536 | -0.1142 | 0.6394 | SOCKET_ElevPanel | 채우는 바 |
| `SM_Gauge_Housing` | MESH | -0.9247 | 0.4487 | 1.3734 | SOCKET_ElevPanel | 외곽선/배경 |
| `SM_Gauge_Labels` | MESH | -0.7650 | 0.3151 | 1.0801 | SOCKET_ElevPanel | 눈금/숫자 텍스트 |

모든 오브젝트가 `SOCKET_ElevPanel` 프리팹 아래에 있음.

### 1.2 눈금(Tick) 위치

Labels 메시의 텍스트 클러스터 5개 (0%, 25%, 50%, 75%, 100%):

| 눈금 | 월드 X 좌표 | 클러스터 크기 |
|---|---|---|
| 0% | -0.7534 | ~0.01 unit (텍스트 폭) |
| 25% | -0.4969 | ~0.01 unit |
| 50% | -0.2405 | ~0.01 unit |
| 75% | 0.0313 | ~0.01 unit |
| 100% | 0.2899 | ~0.01 unit |

텍스트 메시는 2868개 정점으로 구성.

## 2. 게이지 바가 자라는 축

**축**: **X축 (월드 좌표계)**

**근거**:
- Fill의 Y 폭: 0.0446 unit (미미)
- Fill의 Z 폭: 0.0496 unit (미미)
- Fill의 X 폭: 0.6394 unit (압도적)
- 눈금 5개의 분포도 모두 X축을 따라 균등 분포 (약 0.254 unit 간격)

---

## 3. 바의 시작점(0%)과 현재 모델링된 끝점

### 3.1 시작점 (0%)
- **월드 X**: -0.7536
- **근거**: 눈금 0% 위치와 Fill 최소값이 일치 (차이 0.0002 unit = 십진 오차)

### 3.2 현재 끝점
- **월드 X**: -0.1142
- **100% 눈금 위치와의 거리**: 0.2899 - (-0.1142) = 0.4041 unit
- **현재 채우기 백분율**: 0.6394 - 0 / 1.0433 × 100 = **61.26%**

**해석**: 현재 모델링된 Fill 바는 0%부터 약 **61%까지** 만 채워 있는 상태.  
사용자 지적 "67%" 과 약 6% 차이 (육안 추정과 정밀 측정의 차이로 판단).

---

## 4. 100%에 해당하는 월드 좌표

- **월드 X**: **0.2899**
- **근거**: Labels의 "100%" 텍스트 클러스터 중심
- **0%부터의 거리**: 0.2899 - (-0.7534) = 1.0433 unit

---

## 5. Unity에서 필요한 스케일 배수

### 5.1 계산

```
현재 Fill 폭:     0.6394 unit
필요한 폭:        1.0433 unit (0% ~ 100% 전체)
스케일 배수:      1.0433 / 0.6394 = 1.6317
```

### 5.2 결론

**Unity에서 SM_Gauge_Fill의 X 스케일을 1.6317배 확대하면 100%일 때 끝까지 찰 것임.**

**구현 방안** (예시):
- SM_Gauge_Fill의 localScale.x를 1.6317배 하거나
- 상위 오브젝트의 스케일을 조정하거나
- 프로퍼티 드리븐으로 Fill의 크기를 동적 계산
