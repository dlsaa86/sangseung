## 3. 초기 승객 7명 (확정 — 프로토타입 제작 대상)

| 승객 | 혼자서 이해되는 핵심 행동 | 제공 상태 | 정서 | 위험 |
|---|---|---|---|---|
| **검역관** | 가장 많은 저항을 검역 대상 지정, 첫 정화 안정화 | 검역·봉인·표본 | 절제된 죄책감 | 검역 대상의 다음 스핀 출현률 상승 |
| **배관공** | 선택한 통관의 **세로 직선** 보상 강화 | 압력·통관·파열 | 블랙코미디·생활감 | 다른 두 통관 세로 정화 보상 감소 |
| **폐광의 광부** | 4개 이상 연결 정화 시 인접 저항에 **균열** 생성 | 균열·연결·주변 파괴 | 분노·처절함 | 균열 저항 미제거 시 고정체로 변할 수 있음 |
| **장의사** | 제거 누적을 정상 영혼·빈칸 충전으로 전환 | 제거 수·보관·빈자리 | 차분한 온기 | 기본 정상 영혼 출현률 감소 |
| **검은 벌의 양봉업자** | 남은 증식체를 **벌집**으로 보존해 다음 스핀 재료화 | 군집·잔류·증식 | 기괴하지만 따뜻한 희망 | 증식체 출현률 상승 |
| **전력 검침원** | 첫 전력 임계점에서 직전 발동 탑승물 하나 재발동 | 충전·임계점·반복 | 도덕적 책임 | 층 종료까지 임계점 미돌파 시 보증금 상실 |
| **손가락 없는 도박사** | 추가 스핀에서 배수 유지, 실패 손실 확대 | 추가 스핀·위험·누적 배수 | 자기파괴적 유쾌함 | 실패 시 저장 전력 손실·잔류 대가 단계적 증가 |

**승객별 무게는 전 문서 미명시.** 알려진 것은 장의사 = 화물 2칸 점유, 광부 = 곡괭이용 화물 1칸 필요뿐.

## 4. 초기 장착 아이템 8종 (확정)

| 아이템 | 단독 효과 | 연상 행동 |
|---|---|---|
| **봉인 테이프** | 스핀 종료 시 저항 하나를 봉인해 다음 행동 1회 차단, 위치 유지 | 검역, 누수 봉합, 벌집 밀폐 |
| **압력 조절 밸브** | 선택 통관에 압력 축적, 세로 직선 완성 시 방출 | 배관, 임계점, 파열 |
| **균열 탐침** | 매 스핀 위험도 최고 저항 하나에 균열 부여 | 채굴, 파손 검사, 연쇄 제거 |
| **검은 회수포** | 스핀마다 처음 제거된 저항 하나 보관, 누적 시 정상 영혼으로 반환 | 수습, 표본, 장례 |
| **사선 결속선** | 한 번의 패턴 판정에서 대각선으로 닿은 저항을 연결로 인정 | 갱도 보강, 벌집 연결, 봉합 |
| **소형 축전지** | 첫 초과 전력 일부 저장, 다음 스핀 시작 시 방출 | 검침, 재발동, 손실 보험 |
| **불법 흡입기** | 계약 저항 출현률·정화 보상 상승, **잔류 대가도 강화** | 군집 유인, 도박, 위험 표본 채집 |
| **납추 공구함** | **무게를 크게 늘리는 대신** 과적 상태에서 첫 패턴 배수 강화 | 작업 고정, 압력, 위험 베팅 |

**아이템별 무게 수치 미명시.**

### 4.1 역할 분리 (확정)

- **승객** — 욕망·목적지·무게를 가진 반복 발동 엔진. 행동의 **맥락과 반복 조건**을 만든다
- **장착 아이템** — 공통 상태를 생성·소비·변환. **상태 전달과 방향 전환**을 담당한다
- **소모품** — 즉시 위험 해결 또는 1회 시도. **초기에는 숨은 공명에 참여시키지 않는다**
- **퀘스트 화물** — 장착 아이템과 분리, 공명 엔진 불참

> 승객과 아이템은 동일 효과를 단순 중복하지 않는다.

## 5. 프로토타입 "최소 4종"의 해석

MASTER PRD §4.1은 `승객·부품 최소 4종`이라고만 적고 **어떤 4종인지 명시하지 않았다.**

**채택 기준 (가정)**: 핵심 개편이 확정한 **핵심 공명 시나리오 4개**를 성립시키는 최소 집합.

| 시나리오 | 구성 | 증명하는 것 |
|---|---|---|
| **갱도 수습 엔진** | 광부 + 균열 탐침 + 장의사 | 균열 → 연쇄 제거 → 자원 환원 순환 |
| **봉인된 벌집** | 검역관 + 양봉업자 + 봉인 테이프 | 안정형 도구가 오히려 증식 전략을 안전하게 만드는 **반전 조합** |
| **압력 과전류** | 배관공 + 압력 조절 밸브 + 전력 검침원 | 직선 → 임계점 → 밸브 재발동 순환 |
| **저당 잡힌 행운** | 도박사 + 소형 축전지 + 불법 흡입기 | 보험이 있다는 이유로 욕심을 더 내게 만드는 **심리적 함정** |

→ 최소 집합: 승객 **광부·장의사·검역관·양봉업자** + 아이템 **균열 탐침·봉인 테이프**.
**이 조합은 Notion에 명시된 것이 아니라 추론이다.** `ASSUMPTION_LOG` 등재 대상.

## 7. 공명 매트릭스 (확정 — 개발용, 플레이어 비노출)

각 아이템은 최소 3명과, 각 승객은 최소 **3개 아이템·2명 승객**과 의미 있게 맞물려야 한다.

| 승객 | 강하게 공명하는 아이템·승객 |
|---|---|
| **검역관** | 봉인 테이프(검역 대상 봉인 시 잔류 행동 정지) · 검은 회수포(정상 표본으로 저장, 반환 보상 안정) · 불법 흡입기(유입 계약 저항 첫 대상 자동 검역 — **검역 실패 시 잔류 대가 크게 증가**) · 양봉업자 |
| **배관공** | 압력 조절 밸브(첫 세로 직선이 압력 방출 → 상하 인접 저항에 균열) · 봉인 테이프(누수 칸 고정) · 납추 공구함(과적 중 세로 배수 상승, **파열 가능성 증가**) · 전력 검침원 |
| **폐광의 광부** | 균열 탐침(균열 제거 시 인접 칸으로 1회 전파) · 사선 결속선(대각선 분리 광맥까지 연결 인정) · 납추 공구함(과적 첫 연결 정화가 `낙반`) · 장의사 |
| **장의사** | 검은 회수포(회수 저항도 제거 누적에 포함, 순환 가속) · 봉인 테이프(빈칸 봉인 시 정상 영혼 생성이 먼저 차지) · 소형 축전지 · 광부 |
| **양봉업자** | 봉인 테이프(벌집 봉인 시 공격 없이 확정 유지) · 사선 결속선(벌집 군집 대각선 연결) · 불법 흡입기(**통제 실패 위험 급증**) · 검역관 |
| **전력 검침원** | 소형 축전지(저장 전력이 다음 스핀 첫 임계점 가속) · 압력 조절 밸브(임계점 돌파 시 밸브 재발동) · 납추 공구함(**과적 대가로 중간 임계점 하나 추가**) · 도박사 |
| **손가락 없는 도박사** | 소형 축전지(첫 실패 손실 일부 대납) · 불법 흡입기(고점↑, **잔류 대가 누적**) · 납추 공구함(**실패 시 공구함이 잠겨 무게를 못 줄인다**) · 전력 검침원(**멈출 시점을 놓치기 쉽다**) |

## 8. 상충 관계 (확정)

| 승객 | 이득 ↔ 대가 |
|---|---|
| 배관공 | 지정 통관 세로 보상↑ ↔ **다른 두 통관 세로 보상↓** |
| 장의사 | 제거 → 정상 영혼 전환 ↔ **기본 정상 영혼 출현률 감소** |
| 검역관 | 첫 정화 안정화 ↔ 검역 대상의 다음 스핀 출현률 상승 |
| 양봉업자 | 증식체 보존·재료화 ↔ 증식체 출현률 상승 |
| 검침원 | 재발동 ↔ 임계점 미돌파 시 보증금 상실 |
| 도박사 | 추가 스핀 배수 유지 ↔ 실패 손실 확대 |
| 광부 | 균열 확산 ↔ 미제거 균열이 고정체로 변할 수 있음 |

**동승 금지 조건의 구체 조합은 미작성.**

## 9. 밸런스 기준 (확정)

- 모든 승객은 **혼자서도** 최소 하나의 완결된 플레이 결정을 제공한다
- 모든 장착 아이템은 조합과 무관한 기본 효용을 가진다
- 각 승객: 최소 **3개 아이템**과 강한 공명, 최소 **2명 승객**과 규칙 연결
- 각 아이템: 최소 **3명 승객**과 유효 결합
- **강한 엔진은 보통 2~3개 요소에서 성립**한다. 네 번째 요소는 방향 전환 또는 위험 증폭
- 가장 높은 출력 조합과 가장 안전한 조합을 **분리**한다
- 서사적으로 어울리는 조합이 항상 최강일 필요는 없다

## 10. 적재·무게·과적 (확정 규칙 / 수치 미명시)

- 모든 주요 승객과 부품은 효과와 무게를 가진다
- **총무게가 증가할수록 상승 요구 전력이 증가한다**
- **허용 중량 초과 시 사고 위험과 일부 계약 대가가 증가한다**
- 탑승물은 인벤토리 아이콘뿐 아니라 **엘리베이터 내부에 실제로 보인다**

> 허용 중량 초과는 **금지하지 않고 고위험 빌드로 허용한다.**
> **과적 사고는 숨겨진 무작위 처벌이 아니라 사전에 확인 가능한 감수 위험이어야 한다.**

**무게 → 요구 전력 함수, 허용 중량 임계값, 승객별 무게는 전부 미명시.**
02·09 모두 「아직 결정할 항목」 첫 줄이 *"승객별 무게와 요구 전력 증가량"*이다.

⚠ 과적 효과 후보 중 「무게체·고정체 출현 확률 증가」는 **프로토타입 저항체 2종 범위를 벗어난다.**

### 10.1 무게가 덱 제한으로 작동한다 (확정 — 이 게임 고유의 차별점)

> 고정된 보드 인원수 대신 **적재 중량과 요구 전력이 덱 제한으로 작동한다.**

- 가벼운 입문 승객 다수 → 혼합 시너지
- 무거운 최종 승객 중심 → 소수 정예 엔진
- 과적·사고 위험 감수 → **4명 시너지 강제 완성**

오토배틀러와 달리 조합이 ① 목적지 하차로 무너지고 ② 무게로 제한된다.

## 11. 정보 공개 정책 (확정)

**보여주는 것**
- 승객·아이템 각각의 **단독** 효과
- 무게·목적지·탑승 조건·위험·현재 발동 결과
- **어떤 효과가 어떤 상태를 만들었는지의 운행 로그**

**선공개하지 않는 것**
- `광부 계열` · `정화 2/4` · `과수확 세트` 같은 태그와 카운터
- 추천 문구, 완성 조합 목록, 정답 빌드 이름
- 아직 경험하지 않은 상호작용
- 숨은 공명 점수·조합 티어

### 11.1 금지 설계 6종 (확정)

1. 승객 초상화 아래에 직업 태그와 `2/4` 카운터 표시
2. 아이템 설명에 특정 승객 이름 명기
3. 네 개의 정확한 부품을 강제하는 정답 조합
4. 단독으로는 무의미하고 특정 짝과 있을 때만 작동하는 승객·아이템
5. 공명을 숨긴 채 결과만 크게 증가시켜 원인 불명으로 만드는 방식
6. 발견 조합을 영구 정답표로 만들어 체크리스트화하는 방식

### 11.2 발견을 전달하는 연출 (확정)

- 승객이 특정 아이템을 짧게 바라보거나 손으로 만진다
- 배관공은 밸브를 두드리고, 검역관은 테이프의 제조일을 확인하며, 광부는 탐침 끝을 갈아 준다
- 대사는 *"이걸 장착하면 시너지 발생"*이 아니라 **직업적 반응으로만** 쓴다
- 첫 공명 시: `균열 탐침 반응 → 광부의 낙반 → 장의사의 회수`처럼 **사건 순서**를 로그와 애니메이션으로 표시
- **화면 중앙에 조합 이름이나 보너스 수치를 크게 띄우지 않는다**

## 14. 승객 서사 구조 (후보)

**공개 5단계**: 첫 만남 → 탑승 중 → 룰렛 반응 → 중간 고백 → 목적지 → 후유증

## 15. 승객 반응 시스템 (확정)

### 15.1 프로토타입 반응 이벤트 10종

### 15.2 표현 채널

고개·시선 전환 / 몸을 기대거나 난간을 잡는 짧은 모션 / **1문장 이하의 짧은 대사** /
웃음·한숨·호흡·기도·비난 같은 비언어 음성 / **다른 승객과 상반된 반응**.

### 15.3 구현 제약 (확정)

- 긴 대화 트리와 립싱크는 프로토타입 제외
- 반응은 `PassengerReactionSet` 데이터로 이벤트별 교체 가능
- 캐릭터 최종 모션은 **승인 대기**. 초기에는 공용 리그 + 단순 LookAt·상체 모션
- **한 이벤트에서 모든 승객이 동시에 말하지 않는다.** 우선순위·쿨다운·최대 동시 반응 수를 둔다

### 15.4 「최소 반응 세트」의 유력 후보

초기 7명의 **이상 징후 7개**가 가장 유력하다 (각 승객이 1개씩 보유):

- 검역관 — 플레이어를 처음 보면서도 이전 검역 기록이 있다고 주장한다
- 광부 — 헬멧 램프가 결과판이 아니라 **바닥 아래**를 비춘다
- 장의사 — 빈 관 안에서 현재 탑승객 중 한 명의 기침 소리가 난다
- 양봉업자 — 벌통에서 벌 대신 작은 사람 목소리가 들린다
- 검침원 — 계량기의 누적 사용량이 **플레이어 나이와 같다**
- 도박사 — 잘린 손가락 하나가 결과판에 심볼처럼 나타난다
